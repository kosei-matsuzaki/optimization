## 4. 判定と反証条件（**run の結果を見る前に書いた**）

- **判定**: **RR の 4 instance 平均 MPR が公表 0.844 の ±0.10 に入れば、食い違いは「1 instance で代表させたこと」で説明がつく**
  ＝ harness 間比較は生き、ただし公表値と比べる行はすべて instance 平均どうしに直す。
- **反証条件 (a)**: **4 instance 平均でも 0.10 以上届かない（＝ 平均 MPR < 0.744）なら、instance 軸でも説明できない**
  ＝ **harness 間比較そのものを落とし、status.md の「書ける主張」7 と 9 の書き直しを俯瞰に上げる**（実行役は status.md を編集しない）。
- **反証条件 (b)**: **instance 間のばらつき（4 本の SD）が その123 の seed ばらつき 0.0238 と同じ桁なら、instance は seed と同じ疑似反復**
  ＝ その149（D=10、r=+0.4899）と合わせて「instance でも n は増えない」が 2 次元で確定する。
  **この場合 (a) の判定は自動的に成立する**（ばらつきが小さいのに 0.18 ずれているなら原因は instance ではない）。
- **副次（RL が回れば）**: **RL − RR の対差の符号が 4 instance すべてで正か。** PIN01 は Score +0.0550 / MPR +0.0688。
  **符号が instance で割れるなら、その153 の「D ≦ 10 で符号は正」は PIN01 に限った主張に縮む。**
- **問題ごとの instance 間相関**（PIN01 対 PIN02/03/04、n=16）**も出す** —— その149 の D=10 の r=+0.4899 と比べるため。
