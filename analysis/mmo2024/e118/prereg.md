## (a) 配置そのもの（Clark-Evans 型）

- 統計量 `T_a` = K 個の最適それぞれについて「他の最適までの最近傍距離」を取り、その平均。
- null = 同じ箱に **K 点を一様独立**に撒いたときの `T_a`（**1000 反復**、CSR）。境界効果は null 側が同じ箱なので吸収される。
- p は両側: `p = 2·min(#{null ≥ T_a}, #{null ≤ T_a}) / 1000`（1 で打ち切り）。α=0.05。
- 有意かつ `T_a` > null 中央値 → **規則的（過分散）**、`T_a` < null 中央値 → **塊（過集中）**。

## (b) 条件つき予測可能性（leave-one-out）

- 各最適 i について `A_i` = i から**他の K−1 個**までの最近傍距離。
- `B_i` = 同じ K−1 個を既知集合としたとき、**箱に一様に置いた点**から最近傍既知最適までの距離の**中位数**（一様点 2000 個）。
- 検定は i を単位にした **Wilcoxon 符号付順位（両側、α=0.05、`method="exact"`）**、効果量は rank-biserial と `median(A)/median(B)`。
- **`A` が有意に短い** → 「見つけた最適は次の最適の在り処を教える」＝ 記憶に意味がある。

## 棄却条件（判定は下の 3 分岐のみ。あとから増やさない）

- **(a) と (b) の両方で、16 問中 12 問以上が一様 null と区別できない**（α=0.05）なら、
  **この suite の最適配置には探索が使える構造が無い**と書き、Lobo らの予想が連続側でも成り立つと記録し、
  **「構造を使う機序」を候補から全部落とす**（記憶・盆地間の外挿・archive からの誘導）。
- **5 問以上で有意なら**、**どの問題でどの型（規則的／塊）か**を列挙し、その問題群を次の対象集合にする。
- **中間（5-11 問）なら**、構造がある問題とない問題で `Restart-Lander` との差が違うかを見る
  （相関しないなら構造は律速ではない）。
