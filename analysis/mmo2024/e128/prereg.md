作成: 2026-09-15 12:3x UTC（run 開始前）。

## 何を測るか

その127 は RR-CMA-ES（de Nobel+ 2024、著者実装 `modcma==1.2.0` の `c_maes.repelling`）を
16 問 × **seed 0** × 正規予算 50 万で回し、`eps_loose+dedup`（r=0.05·span=0.5）で採点して
**16 問平均 Score 0.5377**（公表値 0.5730 との差 −0.0353）を得た。
**残っている留保の筆頭は seed が 1 本しかないこと**（公表値は 15 インスタンス平均）。

**今回**: **同じ駆動・同じ設定で seed を 100 に変えた 16 run だけを足す。**
（`niching_baseline.py:281` の規約で seed_index 1 ＝ seed 100。`e115/s1/descents` の null と同じ seed。）

- **新規 run は RR-CMA-ES 側の 16 本だけ。** `Restart-Lander`（null）の seed 100 は
  `analysis/mmo2024/e115/s1/descents/*_seed100.csv.gz` に 16 問すべて保存済み ＝ **追加評価ゼロ。**
- **MC-ESO / NMMSO は回さない**（seed 100 のダンプが無いので、今回の 2 seed の比較には入れない）。
- **掃引はしない。`restart_strategy` は RESTART のまま動かさない**（掃けば競技仕様 §5 の ad-hoc 調律。その127 §7b）。
- **採点は e115 の `rule_indices` / `score` / `paired` を import する。新しい規則も新しい統計量も定義しない。**
- **`optima_pos` は腕の中で一切参照しない**（`run_rrcma.py` は その127 のものをそのまま使う）。

## 事前に登録する判定

**(J1) 公表値の再現。** **2 seed 平均（seed 0 と seed 100 の 16 問平均の平均）の RR-CMA-ES Score が
公表値 0.5730 の ±0.05 に入り続けるなら、「この採点器は公表値を 2 seed で再現する」と書く。**
±0.05 から外れたら**移植の精度の問題**として扱い、**`restart_strategy` の 3 択（RESTART / IPOP / BIPOP）を
1 回だけ確認してよい**（枠が残っていれば。掃引ではなく確認 1 回）。
**それでも合わなければ「RR-CMA-ES の実装差は ±0.05 では詰められない」と書き、
比較の言い方を「著者実装をこの採点器に載せた値」に限定する。**

**(J2) 直接対決を 2 seed で取り直す。** `Restart-Lander` − RR-CMA-ES の対比較（問題ごと、
Wilcoxon exact ＋ rank-biserial）を **(a) seed 100 単独**と **(b) 問題ごとの 2 seed 平均**の両方で出す。
**その127 の seed 0 は Score +0.0907（10/2/4、p=0.0295、rb=+0.657）。**

**(J3) 何が反証するか（これが起きたらそのまま書く）。**
**seed 100 で `Restart-Lander` が RR-CMA-ES に負ける**（16 問平均 Score 差が負、または
対比較が RR-CMA-ES 側に有意）**なら、その127 の +0.0907 は seed 1 本の当たりだった**ことになり、
[status.md](status.md) の「null は競技次点にも勝つ」は 1 seed の主張に戻る。
**2 seed 平均でも差が正で有意なら、その主張は 2 seed に強くなる。**
**中間（seed 100 では正だが有意でない）なら、「差の向きは 2 seed とも同じ、有意性は 16 問 × 2 seed では足りない」と書く。**

**(J4) seed 間のばらつきそのものを記録する。** RR-CMA-ES と `Restart-Lander` の
**16 問平均 Score の seed 0 → seed 100 の差**を両手法について書く。
**その123 の測定（問題別のばらつきは `s_seed` 0.0563 対 `s_inst` 0.0421）に対して、
「−0.0353 が seed 1 本ぶんのずれで説明できる大きさか」を見るのが目的。**
**注意**: **2 点では SD を主張しない**（その123 の教訓）。書けるのは差の実値だけ。
