## 事前に登録する判定

**(J1) seed 200 単独の対比較。** `Restart-Lander` − RR-CMA-ES を問題ごとに取り、
Wilcoxon exact ＋ rank-biserial で出す。
**p < 0.05 かつ差が正なら、seed 100 の p=0.083 は 1 本のぶれだったと書く。**

**(J2) 3 seed 平均の対比較（主判定）。** 問題ごとに 3 seed（0 / 100 / 200）を平均してから対を取る。
**p < 0.05 なら「16 問の対で有意」と書いてよい。**

**(J3) 何が反証するか。** **seed 200 で `Restart-Lander` − RR-CMA-ES の 16 問平均 Score 差が負に振れる**なら、
**「null が競技次点に勝つ」は 3 seed 中 1 本が逆 ＝ 主張として書けない。起きたらそのまま書く。**
**3 本目も単独で 0.05 を通らない場合は、「16 問 × 1 seed では検定力が足りない」を確定させ、
以後は単独 seed の p を主張に使わない**（差の向きと大きさ、および 3 seed 平均だけを書く）。

**(J4) 公表値との残差。** RR-CMA-ES の **3 seed 平均 Score** を公表値 0.5730（出典 1 本、15 instance 平均）と比べ、
**±0.05 の内側か**を書く。**その128 が「16 問平均の seed ノイズは 0.006-0.014 しかない」を出しているので、
3 本目でこれが崩れるか（＝ seed 幅の推定が 2 点の偶然だったか）も併せて記録する。**
**3 点なので SD は書いてよいが、n=3 の SD であることを明記する。**
