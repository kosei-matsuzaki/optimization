## 4. 反証条件（事前に固定する。run の前に書いた）

* **(a) 10 問の対差で勝ち数が 6 未満、または p ≥ 0.05 なら、<u>CEC2013 では有意にならないことが確定</u>**
  ＝ status.md の主張 1 の限定は恒久的になり、この軸は閉じる。
* **(b) p < 0.05 なら主張 1 の限定は外れ、2 つの suite で支えられる。**
* **(c) 打ち切り規則**: **追加 3 問で同点が 2 問以上出たら**（＝ 10 問での同点が 5 以上、有効 n ≤ 5）、
  **両側 Wilcoxon exact の最小 p が 0.0625 > α なので、その時点で (a) と同じ結論に落ちる。**
  その166 §3 の機序（K=6,8 の粒度）は 2D でも変わらない。
* **(d) 2D は その165 が「headroom 無し」と記録した層**なので、**両手法とも MPR 1.00 に張り付く**可能性がある。
  そのときは同点 3 問 ＝ (c) が発火する。

`random.sample(<set>, k)` を 4 箇所書き換える）が要るが、**この回はその手順が
自動化モードの分類器に `Untrusted Code Integration` として拒否された。**
`pip install -r requirements.txt` は従来どおり `pynmmso` の wheel ビルドで落ちる。
**＝ 対照側（NMMSO）の 9 run は出せない。**
