## 2. 差し替える測定 — **被覆係数 c（de Nobel+ 2024 §4.3, Eq.10-11）**

**この harness が既定のまま使っていて、かつ論文が「冗長な再起動の量を決める」と名指ししている free parameter が 1 つだけある。**
**`es.p.repelling.coverage`（modcma の既定は 20.0）。** Fig. 5/6 は **c が小さいほど反発領域が大きく、冗長な再起動が減る**ことを示している。
**＝ 容疑「再起動が冗長である」の直接のつまみ。**

- **腕**: **c ∈ {2, 20（既定 ＝ その153 の配線）, 200}**。D=5・16 問・PIN01・seed 0・予算 250,000。**48 run。**
- **計器**: その153 の保存物では **キュー 1 (ii) が要求した「1 再起動あたりの評価回数」と「打ち切り理由」は出せない**
  （`evals` 列は空文字、`stop` 列は taboo/final のタグであって理由ではない）。**なので `es.run()` を `es.step()` の手回しに変え、
  再起動ごとに `evaluations` と `criteria.reason()` を記録する。**
- **採点**: `e115/analyze.py` の `rule_indices` / `score` をそのまま import（`eps_loose+dedup`, r=0.05·span）。**新しい統計量は定義しない。**

## 3. 関門（先に通す）

- **G1**: **c=20 の腕が その153 の保存物を再現すること。** 16 問の archive サイズと 16 問平均 MPR 0.6619 / Score 0.7220 を照合し、
  **MPR の差が 0.01 未満**であること。外れたら「step 手回しが `es.run()` と違う」ので、それ自体を報告して腕の比較はしない。
- **G2**: 各 run の `evals` が予算 250,000 の 99% 以上。

## 4. 判定と反証条件（先に書く）

- **判定（配線が原因）**: **3 水準のどれかで 16 問平均 MPR が 0.844 の ±0.10（≧ 0.744）に入れば、赤字 −0.1821 は配線 ＝ c の既定値のせい**と確定する。
- **反証条件 (a)**: **MPR が c に対してほぼ平ら**（3 水準の最大 − 最小 < 0.05 ＝ その123 の RR の 1 seed SD 0.0238 の約 2 倍）なら、
  **容疑「再起動の冗長性」は棄却**され、**配線仮説は公表文書が名指しする唯一のつまみを失う。**
  その場合、赤字の残る説明は **(1) 採点器（`land_opt` 帰属 対 `how_many_goptima`）、(2) 公表値の条件の読み違い（15 instance 平均 対 PIN01 1 本）** の 2 つだけになる。
- **反証条件 (b)**: **c を小さくすると MPR が<u>下がる</u>**なら、反発領域の拡大は大域最適の近傍まで塞いでいる
  （de Nobel+ 2024 §5 が BBOB F4 で報告している副作用）＝ **既定 20 は下限側ではなく既に当たりに近い**ことになる。
- **容疑「再起動の回数」そのものの検査**: **1 run の再起動本数を実測する。**
  キュー 1 は「D=5 は 26.2 本（1 本 9,500 評価）」と書いているが、**これは archive のサイズであって再起動の本数ではない**（その153 の保存物には本数の列が無い）。
  **実測が 26 本前後なら容疑は生き、桁で多ければ容疑は「本数」ではなく「本数あたりの当たり率」に移る。**
