# その160 事前登録 — キュー 1「検出規則の上界を引く」

**2026-09-23 12:30 UTC claim。最適化 run ゼロ・追加評価ゼロ・`core/` 不変・MC-ESO の既定不変。**

## 問い（キュー 1 の文をそのまま）

**いちばん甘い数え方でも公表 0.844 に届かないなら、赤字は測り方ではなく到達域である。**

測り方の容疑は 3 本閉じている（報告点数 その154 ／ 被覆係数 c・再起動本数 その155 ／ instance その157）。
残るのは **検出規則**（報告した点を「相異なる大域最適の検出」に数える規則）1 本だけ。
仕様書 `competition_setup_TR2024001.txt` §4 は PR を「目標精度 ϵf で検出された大域最小の割合」としか書かず、
**点を最適へ割り当てる規則を書いていない**。配布コードに採点器は無い。
＝ この harness の「最近傍帰属 ＋ f 閾値」は仕様が許す範囲の中で選んだ 1 つにすぎない。

## 測るもの（入力はすべて保存物。追加評価ゼロ）

`e153`（PIN01）＋ `e157`（PIN02/03/04）の D=5 × 16 問 × 2 手法 = 128 run を、**同じ報告点から 4 通りに採点し直す**。
報告規則は `eps_loose+dedup`（r=0.05·span）で固定し、**変えるのは採点器だけ**（UB2 を除く。下記）。

| 記号 | 報告集合 | 検出の数え方 | 位置づけ |
|---|---|---|---|
| **LB** | `eps_loose+dedup` | **最近傍帰属**（`land_opt` の相異なり数）。同一盆地の複数点は 1 つに潰れる | 現行 ＝ 記録値の再現（関門 G1） |
| **MID** | `eps_loose+dedup` | **半径つき最大マッチング**（点 i は ‖x_i − o_j‖ ≤ R=0.05·span の最適 j にだけ割当可、1 対 1） | 距離を見る規則の中でいちばん甘い側。**診断であって判定には使わない** |
| **UB1** | `eps_loose+dedup` | **距離を一切見ない貪欲割当** ＝ det = min(#{f ≤ ϵ}, K) | **事前登録した上界**（キュー 1 の文の (ii)） |
| **UB2** | **dedup を外す**（f ≤ f_min + 1e-1 の全点） | 距離を一切見ない貪欲割当 | **UB1 の弱点を塞ぐための追加**（下記） |

**UB2 を足す理由（設計上の判断。キュー 1 の文からの逸脱ではなく補強）**:
UB1 は報告規則を `eps_loose+dedup` に固定するが、**この報告規則自身が r=0.05·span の空間的間引きを含む**ので、
**距離を見ない採点器に切り替えても、距離はすでに報告側で効いてしまっている。**
＝ UB1 は「上界」と名乗るには弱い。**合法な報告規則（K も f\* も使わない）と採点規則の<u>両方</u>で最も甘い組が UB2** で、
これがこの 128 run の MPR の天井である。**判定は UB1 と UB2 の両方で書く。**

## 判定（事前登録）

- **UB（UB1 および UB2）の 4 instance 平均 MPR が公表 0.844 に ±0.10 で届かないなら、検出規則も閉じる**
  ＝ 赤字は測り方ではなくこの配線の到達域であり、「公表値と MPR で並ぶ」は今後どう測っても書けない（俯瞰に上げる）。
- **反証条件 (a)**: **UB1 が 0.844 を跨ぐ** ＝ 赤字の少なくとも一部は検出規則である。
  その76 の「採点器は向きが逆」は CEC2013 限定の結論だったことになり、`acceptance_topology.md` その155 §6 の表に訂正が要る。
- **反証条件 (b)**: **UB2 は跨ぐが UB1 は跨がない** ＝ 効いているのは検出規則ではなく**報告側の空間的間引き**である。
  その場合、赤字の帰属先は「検出規則」ではなく「報告規則（dedup 半径）」に移る。
- **反証条件 (c)**: **MID が LB を 16 問平均で 0.02 以上上回る** ＝ 最近傍帰属が同一盆地内の点を過小に数えている。

**どちらに転んでも現行規則は変えない**（上下界のどちらが公表の規則かは決められないので、主張は「幅」で書く）。
