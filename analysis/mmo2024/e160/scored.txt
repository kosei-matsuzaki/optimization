## 7 —— **公表の (MPR, mean-F1) の対を逆算すると、公表側の報告点数は 2K 付近になる**（公表値だけを使う代数。測定ではない）
  F1 = 2pr/(p+r) を p について解く（**MPR と mean-F1 が同じ 5 水準の平均だと仮定した近似**）:
  D=5: 公表 MPR 0.844 / mean-F1 0.585 -> precision 0.4476  -> 報告点数 n = r·K/p = **1.89·K**（K=20 なら 37.7 点、K=10 なら 18.9 点）
  D=20: 公表 MPR 0.476 / mean-F1 0.413 -> precision 0.3647  -> 報告点数 n = r·K/p = **1.31·K**（K=20 なら 26.1 点、K=10 なら 13.1 点）
  この harness の RR-CMA-ES D=5: 報告点数 10.38 点（16 問平均 K = 15.0 なので 0.69·K）、MPR 0.6905 / mean-F1 0.8001
  この harness の Restart-Lander D=5: 報告点数 11.05 点（16 問平均 K = 15.0 なので 0.74·K）、MPR 0.7259 / mean-F1 0.8257
  -> **公表側は 2K 付近まで報告して recall を買い precision を捨てている**が、**その154 が示したとおり<u>この harness の run では報告点数を 100 点まで上げても MPR は動かない</u>** ＝ **同じ報告点数にしても届かない ＝ 差は報告でも採点でもなく到達域。**
