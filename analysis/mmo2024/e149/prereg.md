**変えたのは instance だけ。** 予算（正規 50 万）・D=10・seed 0・報告規則（`eps_loose+dedup`,
r=0.05·span=0.5）・採点器（`e115/analyze.py` の `rule_indices` / `score` / `paired`）・

**`core/` は 1 ビットも触らない。新しい統計量は 1 つも定義しない。MC-ESO / NMMSO は回さない。**

## 判定（事前登録）

**主判定 J1**: **PIN01 の 16 対 ＋ PIN02 の k 対（n = 16 + k）で、Score 差
（`Restart-Lander` − RR-CMA-ES）の Wilcoxon 符号順位検定（exact・両側）が α=0.05 を通れば、
「null は競技次点に勝つ」を初めて主張として書ける。** 効果量は rank-biserial を併記。
**MPR と mean-F1 は内訳として必ず併記する**（方針欄 2026-09-11 (1)）。

**反証条件 (a)**: **通らず、かつ n=16+k の平均差が +0.05 を下回るなら**、margin は
「向きは正、有意でない」で確定させ、**この路線を閉じる**（PIN03 を足さない。
status.md の「脆い」8 を最終形として凍結する提案を俯瞰に上げる）。

**反証条件 (b)**: **PIN02 側だけの平均差の符号が負なら**、PIN01 の +0.0694 は
1 インスタンスの当たりだったことになる —— **頭の表から margin の行を落とす提案を俯瞰に上げる。**

## 追加で必ず出すもの（k < 16 のときの偏りの検査。追加評価ゼロ）

**その131 の J5（打ち切った 11 問は `Restart-Lander` 寄りの部分集合だった）が
この回でも起きうる**ので、**k < 16 なら次を必ず出す**:

- **PIN01 の 16 対を、完走した k 問だけに制限した平均差**を、全 16 問の +0.0907（seed 0）と並べる。
  **この 2 つが大きく違えば、k 問という部分集合そのものが偏っている。**
- **釣り合い型の副判定**: **同じ k 問の PIN01 対 ＋ PIN02 対（n = 2k）** でも Wilcoxon を取る
  （各問題が両インスタンスを 1 つずつ出すので、問題構成の偏りが相殺される）。
- **完走した k 問の群 A / 群 B の内訳**（その129 は群 B を半分落とした）。

## 何が起きれば仮説が否定されるか（1 行）

**「instance 軸で n を増やせば margin が有意になる」は、n=16+k で p ≥ 0.05 のままなら否定される。**
**そのとき (a) が発火すれば路線を閉じ、(b) が発火すれば主張の行そのものを落とす。**
