# その147 事前登録 —— キュー 2: `sigma_ratio` を振る（2 つ目のつまみの監査）

**書いた時刻: 2026-09-20 06:47 UTC（run の投入前、集計コードは 1 行も書いていない時点）。**

## 何を測るか

`Restart-Lander` の `sigma_ratio` を **0.2** と **0.05** にした 2 腕
（`Restart-Lander-s020` / `Restart-Lander-s005`、**`descent_budget=12500` は据え置き**）を
**新 suite M01-M16（D=10、PIN01、正規予算 50 万評価、seed 0）で 1 本ずつ**回す（**新規 run は 32 本**）。

**変えたのは driver の `_METHODS` に 2 行足しただけ**（`scripts/niching_baseline.py`）。
`core/` は 1 ビットも触っていない。既存の `Restart-Lander` / `-1540` / `-3000` / `-6000` の行も不変
＝ **記録済みの値は全部そのまま。** MC-ESO / NMMSO / RR-CMA-ES は回さない（保存値と対にする）。
現行 null（σ=0.1）も回さない —— `e115/descents`（seed 0）が対照 ＝ **この水準は追加評価ゼロ**。

## なぜ 0.2 と 0.05 か（掃引ではなく対照）

`sigma_ratio=0.1` は `core/optimizers/restart_lander.py:56` の直書きで、**この研究が置いた値**
（その103 のもので、MC-ESO の σ_init ではない）。**0.2 は MC-ESO の σ_init そのもの**
（`core/optimizers/mceso.py:216`）＝ **その145 の 1540 が「MC-ESO の hunt 長」だったのと同じ揃え方**で、
**「null を MC-ESO の σ にすると何が起きるか」に答える点**。**0.05 は対称を取るための反対側の点**で、
この値自体に根拠は無い（2 倍 / 半分で 0.1 を挟む）。

## 読み A（判定。先に書く側）

**量**: 16 問平均 Score（`eps_loose+dedup`、`r = 0.05 × span`、MPR と mean-F1 の平均 ＝ その115 の合法な最良腕）。
**採点は `e115/analyze.py` の `rule_indices` / `aggregate` / `paired` / `mean_of` をそのまま import する。
新しい統計量は 1 つも定義しない。**

**関門（判定の前に通す）**: `e115/descents`（現行 null σ=0.1、seed 0）を同じ経路で再採点し、
**`e116/ranking_d10.csv` の `arm=legal` 行と 16 問 4 桁一致すること**（許容 5e-5）。外れたら判定に進まない。

**比較先（すべて既存の記録値。新しく測らない）**:
現行 null σ=0.1 **0.6284**（その116）／ NMMSO（公表設定 10·D）**0.4144**（その139）／ MC-ESO **0.1385**（その116）。

**統計**: 問題を対の単位とした両側 Wilcoxon exact（n=16）＋ rank-biserial。**σ=0.1 − 各腕**の向きで報告する。

## 事前登録した反証条件

- **(A2)** **どちらかの腕の 16 問平均 Score が 0.4144（NMMSO）を下回ったら発火。**
  その場合、**頭の結果は 2 個目のつまみにも依存する** ＝ 「null が勝つ」は
  「この研究が選んだ 2 点の設定で勝つ」としか書けない。**主張は書き換えず、俯瞰に上げる。**
- **不発なら**（2 本とも 0.4144 超）、**`sigma_ratio` については監査が通る** ＝ 弱い環 1 の半分が閉じる。
  さらに **2 本とも 0.6284 の近傍（±0.05）に留まるなら**「頭の Score は σ の 4 倍の幅に鈍感」と書ける。

## 読み B（機序。副次だが必ず記録する）

**その145 は「広さは配置が作る・深さは hunt 長が作る」を出した。** その読みの σ 側の検算:

- **必ず記録する量**: **0.2 の腕の 1e-1 被覆**（その113・その145 と同じ定義
  `detected(eps) = |{land_opt : best_f <= eps}| / K`、降下ダンプから。**追加評価ゼロ**）。
- **事前登録した予測**: **σ を 2 倍にしても 1e-1 被覆は動かない**（σ=0.1 の値の ±10% 内）。
  **予測どおりなら「配置」は draw の一様性そのものであって σ ではない**と一段強く書ける。
  **外れたら**（σ で 1e-1 被覆が 10% 超動く）、**その145 の「広さは配置」は「広さは配置と σ」に弱まる**
  ＝ 読み B の結論を書き換える必要があり、俯瞰に上げる。
- **深さ保持率（@1e-5 ÷ @1e-1）**も 3 水準そろえて出す（その145 の 0.850 / 0.186 と同じ定義）。

## 枠が binding したときに何を落とすか（その142 の教訓。run の前に決める）

**腕を落とす。問題は落とさない**（16 問揃わない腕は Score の比較可能性が無い）。
投入順は **1 問につき 2 腕を隣り合わせ、群 A（M01-M08、K=20）と群 B（M09-M16、K=10）を交互**
（その133・その146 と同じ）＝ 途中で切れても片腕だけの問題を作らない。
**計画規則の実績**: その146 の同型 32 run が 22.0 分（1.45 run/分）、その145 が 16 run 13.9 分（1.15 run/分）
＝ **22-28 分の見込み。** 25 分で 32 本が揃わなければ、**揃っている問題だけで集計し「部分結果」と明記する**。
