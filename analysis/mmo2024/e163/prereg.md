# その163 事前登録 — キュー 1「D=20 で `descent_budget` を上げると 1 降下あたりの当たり率は上がるか」

**書いた時刻: 2026-09-24 06:33 UTC（run を投入した直後、採点前）。以後この節は書き換えない。**

## 1. 何を測るか

**`Restart-Lander-25000`（`sigma_ratio=0.1` は据え置き、`descent_budget` だけ既定 12500 の 2 倍の 25000）を
M01-M16 / D=20 / PIN01 / seed 0 / 正規予算 `floor(50000x20)` = 100 万で 1 本ずつ = 16 run。**

**その151（既定 12500）と変えたのは `--methods` の 1 語だけ**（次元・instance・seed・予算・報告規則
`--report-rule current`・採点器 `eps_loose+dedup` r=0.05*span はすべて同一）＝ **対は条件 1 個の差。**
**腕は `scripts/niching_baseline.py` の登録行 1 個**（`core/` は 1 行も触っていない。MC-ESO の既定は不変）。
**MC-ESO / NMMSO / RR-CMA-ES / 他の `descent_budget` 水準は回さない。対照は追加評価ゼロ。**

**1 水準に絞る理由**: **1 サイクル 40 分という規則**（その151 の実績で 16 run ≒ 42 分）。
**2 水準は入らない。50000 が要るなら次のサイクル。**

## 3. 仮説と、それを外す形

**仮説**: **D=20 では降下長が binding で（未到達の 42.3% が `maxfevals`）、上限を 2 倍にすれば
1 降下あたりの当たり率（初出 i）が上がり、16 問平均 Score も上がる。**

**同時に効く反対向きの力を先に書く**: **予算 100 万は不変なので、1 降下が長くなれば降下本数は減る**
（上限どおりなら 117.7 → 最悪で約半分）。**当たり率が上がっても本数の減少に食われれば Score は動かない。**
＝ **この実験は「当たり率」と「本数」の積を見るもので、当たり率だけ上がっても仮説は通らない。**

## 4. 判定（事前登録。採点前に固定する）

- **主判定**: **16 問平均 Score の対差（25000 − 12500）と、16 問対の両側 Wilcoxon（exact、α=0.05）＋ rank-biserial。**
- **反証条件 (a)（キューが名指ししたもの）**: **|Δ Score| < 0.0066（その123 の seed SD）かつ対検定が非有意**
  ＝ **長さは D=20 でも結果に binding ではない。その158 の副産物は診断値であって帰結を持たない。**
  **この軸を閉じ、「再起動一族は高次元では原理的に届かない」で確定する。**
- **反証条件 (b)**: **Δ Score が +0.0066 を超え、かつ対検定が有意**
  ＝ **[status.md](status.md) の「D=20 では 2 手法の差は消える」は配線依存だった ＝ その152 の結論に範囲の但し書きが要る。俯瞰に上げる。**
- **反証条件 (c)**: **Δ Score が −0.0066 を下回る（有意に悪化する）**
  ＝ **D=20 でも 12500 は最適の側にあり、その145〜その148 の「長さは効かない」は D=20 まで伸びる**
  （D ≦ 10 限定という但し書きが要らなくなる。**これも情報であって失敗ではない**）。
- **機序の内訳（(a)(b)(c) のどれが出ても必ず併記する。方針欄 2026-09-11 (1) と キュー 1 の指定）**:
  1. **Score / MPR / mean-F1 の 3 つ**（どちらが動いたか分かる形で）
  2. **その158 の 3 分類**（初出 i / 重複 ii / 未到達 iii、ε=1e-5 と ε=1e-1 の両方）
  3. **`stop` の内訳**（**`maxfevals` の割合が下がったか** —— 下がっていなければ 25000 も binding）
  4. **降下本数**（当たり率の上昇が本数の減少に食われていないか）
  5. **問題別も必ず出す**（その162 が名指しした M03 / M11 —— 既定 12500 の実機は 1e-5 到達 0 個、
     降下上限 25,000 の null は M03 で 5 個・M11 で 3 個に届いている。**16 問平均だけ見るとこの 2 問の寄与が薄まる**）

**関門**: **その151 の保存物を同じ採点器で採点し直し、記録値（Score 0.4504 / MPR 0.3831）と 5e-5 以内で
一致しなければ判定を出さない。**（その151 が D=10 の保存物に掛けたのと同じ関門を、対照の側に掛ける。）

**枠が binding して 16 問揃わなかった場合**: **落ちた問題を明記し、完走した k 問だけで対を取る。
群 A / 群 B の本数も出す**（投入順が交互なので偏りは小さいはずだが、確認する）。
