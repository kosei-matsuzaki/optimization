# その164 事前登録 — キュー 1「D=20 で `descent_budget` を 50000 まで上げると飽和するか」

**書いた時刻: 2026-09-24 12:41 UTC（run を投入した直後、採点前）。以後この節は書き換えない。**

## 1. 何を測るか

**`Restart-Lander-50000`（`sigma_ratio=0.1` は据え置き、`descent_budget` だけ その163 の 25000 の 2 倍 = 50000）を
M01-M16 / D=20 / PIN01 / seed 0 / 正規予算 `floor(50000x20)` = 100 万で 1 本ずつ = 16 run。**

**その163（25000）と変えたのは `--methods` の 1 語だけ**（次元・instance・seed・予算・報告規則
`--report-rule current`・採点器 `eps_loose+dedup` r=0.05*span はすべて同一）＝ **対は条件 1 個の差。**
**腕は `scripts/niching_baseline.py` の登録行 1 個**（`core/` は 1 行も触っていない。MC-ESO の既定は不変）。
**他の手法・他の水準は回さない。対照（その163 の 25000、その151 の 12500）は追加評価ゼロ。**

**1 水準に絞る理由**: **1 サイクル 40 分という規則**（その163 の実績で 16 run = 34 分）。**2 水準は入らない。**

## 3. 仮説と、それを外す形

**仮説**: **25000 でも `maxfevals` 打ち切りが 12.7% 残っている（その163 §4）ので、
50000 にすればさらに 1 降下あたりの当たり率が上がり、16 問平均 Score も上がる。**

**同時に効く反対向きの力（その163 で実在が確認された）**: **予算 100 万は不変なので、
1 降下が長くなれば降下本数は減る**（117.7 → 101.5 と既に減っており、50000 では 60〜70 本、
上限どおりなら 20 本前後まで落ちうる）。**この実験は「当たり率」と「本数」の積を見るもの。**

**新しく効く 3 つ目の力（キューが名指しした代償）**: **降下本数が K を下回ると被覆が構造的に頭打ちになる。**
**群 A（M01-M08）は K=20 なので、本数が 20 本前後まで落ちればここで先に効く。**
＝ **群 A / 群 B を分けて見ること**（16 問平均だけでは相殺されて読めない）。

## 4. 判定（事前登録。採点前に固定する）

- **主判定**: **16 問平均 Score の対差（50000 − 25000）と、16 問対の両側 Wilcoxon（exact、α=0.05）＋ rank-biserial。**
- **反証条件 (a)（キューが名指ししたもの）**: **|Δ Score| < 0.0066（その123 の seed SD）かつ対検定が非有意**
  ＝ **飽和点は 25000 と 50000 の間にあり、この軸は閉じる。**
  **「D=20 で降下長は binding、ただし 25000 で頭打ち」で確定する。**
- **反証条件 (b)**: **Δ Score が +0.0066 を超え、かつ対検定が有意**
  ＝ **降下長は 1 run を 20 本程度まで減らしても効き続ける ＝「再起動一族の被覆は本数ではなく
  1 本の深さで決まる」という<u>より強い主張</u>に変わる**（その88・その89 のクラス上限の引き方そのものに関わるので**俯瞰に上げる**）。
- **反証条件 (c)**: **Δ Score が −0.0066 を下回る（有意に悪化する）**
  ＝ **最適の水準は 12500 と 50000 の間にあり、25000 付近が山の頂 ＝ 「長さを上げれば上がる」は単調ではない。**
  **本数が K を下回る代償が実測で出たことになるので、群 A / 群 B の分離を機序として書く。**
- **機序の内訳（(a)(b)(c) のどれが出ても必ず併記する。方針欄 2026-09-11 (1) と キュー 1 の指定）**:
  1. **Score / MPR / mean-F1 の 3 つ**（どちらが動いたか分かる形で）
  2. **その158 の 3 分類**（初出 i / 重複 ii / 未到達 iii、ε=1e-5 と ε=1e-1 の両方）
  3. **`stop` の内訳**（**`maxfevals` の割合がゼロに向かうか** —— 向かっていなければ 50000 も binding）
  4. **降下本数**（当たり率の上昇が本数の減少に食われていないか）＋ **本数が K を下回る問題の列挙**
  5. **問題別**（とくに **M03 / M11** と、その163 で唯一下がった **M10**、および **12500 で `maxfevals` が
     1 度も出ない M07 / M08 / M15**（腕が発火しえない対照群 —— ここは 3 水準とも同一 run になるはず））
  6. **群 A（K=20、M01-M08）と群 B（K=10、M09-M16）を分けた平均**（本数 < K の代償を読むため）

**関門**: **その163 の保存物を同じ採点器で採点し直し、記録値（Score 0.4922 / MPR 0.4188）と 5e-5 以内で
一致しなければ判定を出さない。**（その163 が その151 の側に掛けたのと同じ関門を、今回の対照に掛ける。）

**枠が binding して 16 問揃わなかった場合**: **落ちた問題を明記し、完走した k 問だけで対を取る。
群 A / 群 B の本数も出す**（投入順が交互なので偏りは小さいはずだが、確認する）。
