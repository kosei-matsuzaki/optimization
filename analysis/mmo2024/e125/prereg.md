# その125 事前登録 — 着地点近傍への再投入は、採点者の情報なしでも利得が残るか（キュー 2）

**書いた時刻: 2026-09-14 18:38 UTC。run を 1 本も回す前に commit する。**

## 問い

その121 は「着地点から ~`NN` のところに仲間がいて、そこから降ろせば入れる」を示したが、
**球の中心に既知の最適（`optima_pos`）を使っている ＝ 上限であって手法ではない。**
**手法自身が観測できる情報だけで中心と半径を決めても同じ利得が残るか**を測る。

## 腕（3 本。うち 2 本が新規 run、1 本は保存物）

すべて `Restart-Lander` の**降下作用素は 1 ビットも変えない**（isotropic CMA-ES、`sigma_ratio=0.1`、
`descent_budget=12500`）。**変えるのは `restart_lander.py:77` の `x0 = rng.uniform(...)` の 1 行だけ。**

| 腕 | 始点 `x0` | 出所 |
|---|---|---|
| `null`（対照・保存物） | 毎回一様 | `analysis/mmo2024/e115/descents`（seed 0、16 問、座標つき） |
| `reseed`（提案腕） | 確率 `p_reseed = 0.5` で**既存の着地点を一様に 1 つ選び**、その周りの半径 `ρ` の球から一様に引く。残り 0.5 は一様 | 新規 run 16 本 |
| `bhop`（必須対照・素の basin-hopping） | **常に直前の着地点** ＋ 半径 `ρ` の球から一様な摂動。**受理判定は入れない** | 新規 run 16 本 |

**`ρ` は採点者の情報を使わない** —— **着地点集合の最近傍距離の中央値**（各着地点からそれ以外の
着地点までの最小距離を取り、その中央値）。**毎回の再起動で現在の着地点集合から取り直す。**
**着地点が 2 個未満のあいだは `ρ` が定義できないので、両腕とも一様再起動**（同一の規則）。
球は `x0 = land + ρ · u`（`u` は半径 1 の球内一様）で、**箱 [-5,5]^10 にクリップする。**

**`optima_pos` は腕の中で一切参照しない**（その115 の教訓）。ダンプの `land_opt` / `dist` は
**採点にだけ使うオラクル列**で、腕の分岐には入らない。

## 条件

D=10・16 問（`M01..M16-D10-PIN01`）・**正規予算 50 万評価**・**seed 0**（`null` と同一 seed で対）。
**`p_reseed` は 0.5 の 1 水準だけ**（2026-09-13 の俯瞰が 2 → 1 に減らした。掃引はしない）。

## 採点

**その116 と同じ合法規則 `eps_loose+dedup`（`r = 0.05 × span = 0.5`）を e115 の `analyze.py` から
import する。新しい規則も新しい統計量も 1 つも定義しない。** 指標は **MPR / mean-F1 / Score（公式）**
の 5 水準平均（方針欄 2026-09-11 (1)：判定は Score、内訳を併記）。
対照 `null` は **同じコードで採点し直す**（再現の関門: その116 の記録 MPR 0.5644 / Score 0.6284 と
4 桁一致すること。一致しなければ採点経路が壊れているので判定に進まない）。

## 判定（棄却条件。事前に固定する）

主判定量は **16 問平均 MPR**（キュー本文が数値を指定しているため。Score は必ず併記する）。

1. **`reseed` の 16 問平均 MPR < 0.5644**（現行 null）→ **再投入は一様再起動より悪い ＝ 路線を畳む。**
   **群 A（M01-M08）だけで見ても下がるなら完全に畳む。**
2. **群 A の 8 問で MPR が +0.10 以上**（その121 の反実仮想の上限 +0.2269 の半分）→ **腕として意味がある**と書く。
3. **`bhop` が `reseed` と同等以上**（16 問平均 MPR の差が +0.02 未満、または対の Wilcoxon が非有意）
   → **腕としての主張は無い。**結果は「basin-hopping がこの suite で強い」という**測定**として書く。
4. **中間**（1 も 2 も 3 も発火しない）→ **群 A の利得と群 B の損失を別々に書いて比を記録する。**

**群 B（M09-M16）に塊は 1 個も無い**（その118）ので、**利得はどう転んでも 8 問から来る。
群 B で下がらないことを別に確認する**（下がるなら 16 問平均の利得が群 A の利得より小さい理由として書く）。

**この仮説を反証するのは何か（明示）**: 仮説は「自己情報だけで決めた中心と半径でも
その121 の上限の利得が残る」。**反証は (a) 16 問平均 MPR が null を下回ること、
または (b) 群 A の利得が +0.10 に届かないこと、または (c) `bhop` が `reseed` に劣らないこと**
（(c) なら利得は「再投入」ではなく「摂動再起動一般」の性質で、この腕に固有の主張が無い）。

## 検定

16 問で対にした**両側 Wilcoxon exact**（`null` 対 `reseed`、`null` 対 `bhop`、`reseed` 対 `bhop`）と
**rank-biserial**。e115 の `paired()` をそのまま import する。群 A / 群 B は 8 問ずつで別に出す。
**n=8 の exact Wilcoxon の最小片側 p は 1/256 = 0.0039** なので、群別の検定には検出力の限界がある
（その119 の教訓：事前登録の時点で数えた）。**群別は記述として読み、判定は 16 問で行う。**
