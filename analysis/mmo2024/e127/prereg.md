# その127 事前登録 — 公表最良の対抗手法 RR-CMA-ES を、こちらの採点器で同じ土俵に載せる（キュー 1）

**書いた時刻: 2026-09-15 06:35 UTC（run は 06:34:56 に起動済み、結果は 1 つも見ていない）。**

## なぜ測るか

[status.md](../../../docs/status.md) のいちばん弱い環 3 ——
**頭の数字「`Restart-Lander` 0.6284 対 公表最良 0.6080」は、自作採点器の値と他者の採点器の値の比較**である。
配布パッケージ（`external/mmo2024/python_code/`）には問題生成器しか入っておらず、**公式の採点器は存在しない**ので、
突き合わせる相手を作る唯一の方法が**対抗手法を自分で走らせて自分の採点器に通すこと**。

## 何を回すか

**実装は自作ではない。** 競技次点の **RR-CMA-ES** は de Nobel+ 2024
（[arXiv 2405.01226](https://arxiv.org/abs/2405.01226) / PPSN XVIII）で、
その repelling 機構は**著者自身の `modcma`** に `c_maes.repelling` として入っている
（`modcma==1.2.0`、PyPI の manylinux wheel、この環境に install 済み）。
**Zenodo の再現パッケージ（10.5281/zenodo.10997200）はこのサンドボックスから egress 403** なので、
**著者の公開ライブラリのほうを経路に使う。**

**既定値から動かすのは 2 つのモジュールフラグだけ**（ad-hoc な調律をしない ＝ 競技仕様 §5）:

- `modules.restart_strategy = RESTART`（再起動）
- `modules.repelling_restart = True`（taboo 点による反発）
- `sigma0 = 2.0 (= 0.2·span)` / `lambda0 = 10` ほかは**ライブラリ既定のまま**。

**条件は他の問いと同じ**: D=10・16 問（M01-M16）・PIN01・正規予算 **50 万評価**・seed 0。

## 採点（新しい規則も新しい統計量も 1 つも定義しない）

- 規則は **`eps_loose+dedup`（`r = 0.05·span = 0.5`）** を `analysis/mmo2024/e115/analyze.py` から import。
- **報告集合**は RR-CMA-ES 自身の **taboo archive ＋ 最終 global best**。
  **採点者の情報（`optima_pos`）は腕の中で一切参照しない。**`land_opt` はダンプのオラクル列で診断専用。
- 比較先 3 本は**すでに同じ規則で採点済みの記録**（`analysis/mmo2024/e116/ranking_d10.csv` の `legal` 行）。
- 対は**問題ごと**、Wilcoxon signed-rank（exact）＋ A12（`paired` を e115 から import）。

## 関門（これが通らなければ判定に進まない）

1. **`null`（`Restart-Lander`）を今回のコードで採点し直した 16 問平均が、その116 の記録
   MPR 0.5644 / Score 0.6284 と 4 桁一致すること**（その125 と同じ形）。

## 判定（結果を見る前に固定する）

- **主判定**: RR-CMA-ES の **16 問平均 Score**。内訳として MPR と mean-F1 を必ず併記する。
- **RR-CMA-ES の実測が公表値 0.5730 から ±0.05 を超えて外れたら、それ自体が結果**
  （移植か条件の取り違えを疑い、差分を書く。**外れたまま順位の主張には使わない**）。
- **±0.05 の内側に入った場合**: 「0.6284 対 0.6080」は**同一採点器・同一インスタンス・同一予算の直接対決**に変わる。
  そのとき `Restart-Lander` − RR-CMA-ES の対比較（16 問、Wilcoxon ＋ A12）を頭の数字の根拠として記録する。
- **`Restart-Lander` が RR-CMA-ES に負けたら**、読み (A) の「検証待ちの勝ち」は消える。
  その場合 [status.md](../../../docs/status.md) の表の「公表最良超」を撤回し、そう書く。
- **何が仮説を反証するか（明示）**: **RR-CMA-ES の 16 問平均 Score が `Restart-Lander` の 0.6284 以上**なら、
  「無協調の多スタートが競技上位手法に勝つ」という本研究の最有力の主張は**その場で反証される。**
  これは起こりうる結果であり、起きたらそのまま書く。

## 既知の留保（結果を見る前に書いておく）

- **seed は 0 の 1 本**（公表値は 15 インスタンス平均）。問題別の値には seed とインスタンスの留保が両方付く（その123・その124）。
- **`restart_strategy` の選択肢は 3 つある**（RESTART / IPOP / BIPOP）。**掃かない**（掃けば ad-hoc 調律になる）。
  素の `RESTART` を選ぶのは「RR-CMA-ES ＝ 再起動 ＋ 反発」という名前どおりの読みによる。
  **IPOP / BIPOP で値が動く可能性は残るので、留保として書く。**
- **報告集合の定義（taboo archive ＋ 最終 best）はこちらが決めたもの**で、著者の競技提出時の報告規則とは異なりうる。
  ただし**同じ `eps_loose+dedup` を全手法に当てている**ので、比較の土俵としては揃っている。
