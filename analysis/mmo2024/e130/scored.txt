== 反転の機序（追加評価ゼロで特定できた） =================================
**r = 0 は「半径の端点」ではなく「規則の有無」で、そこでは比較そのものが非対称になる。**
  `Restart-Lander` は降下の着地を全部出す（r=0 で 70.1 点、precision 0.146）。
  RR-CMA-ES は自分の taboo archive を報告集合にしているので**既に内部で間引かれている**
  （r=0 で 13.2 点、precision 0.725）。
  **`r = 1e-6*span`（= 1e-5、座標がほぼ同一の点だけを潰す幅）を入れた瞬間に、
  `Restart-Lander` は 70.1 -> 14.8 点（78.9% が重複）、RR-CMA-ES は 13.2 -> 8.9 点（33.0%）。**
  ＝ **r=0 の敗北は「null の報告が冗長」ではなく「片方にだけ間引きを与えていない」こと。**
  これはその125 が測った「着地点は多重集合で、降下の 62.3% は既存の着地と 1e-6 未満」と同じ現象。
  **r=0 で負ける問題は 13/16**（勝つのは M02 +0.0380 / M07 +0.0746 / M12 +0.0146。
  **M07 は RR 側も 72 点報告しており、r=0 で両者の報告点数が同じ桁になる唯一の問題**）。

== MPR 側は定義上、半径に依存しない =======================================
**対比較の MPR 差は r <= 0.2*span の 9 点すべてで +0.1050（基礎 A、p=0.01343）で一定。**
  recall が半径に鈍いので当然だが、**「Score の半分（PR 側）は半径の選択とまったく無関係」**
  という形で書ける。**動くのは F1 側だけ。**
