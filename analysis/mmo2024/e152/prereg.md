## 3. 判定（事前登録）

**主判定 (i)**: **D=20 の 16 問対検定**（両側 Wilcoxon exact、**Score 主**、MPR と mean-F1 を内訳）。
**符号と p を書く。**

**(ii)**: **D=10 の 16 対と合わせた n=32 の対検定。** ただし **(iii) の結果次第で採否が決まる**（下記反証条件 (b)）。

**(iii)**: **D 間の差の相関 r**（Pearson、16 問の `Score(RL) − Score(RR)` を D=10 と D=20 で並べる）。
**その149 の instance 間 r=+0.4899 と比べる。**

- **反証条件 (a)**: **D=20 で符号が反転したら（RR > RL、すなわち 16 問平均差 < 0）、頭の主張は D=10 に限定される。**
  **その場合 status.md の「書ける主張」は全部範囲つきに直す必要がある ＝ 俯瞰に上げる。**
- **反証条件 (b)**: **D 間の相関が r ≥ 0.49 なら、(ii) の n=32 は instance と同じ疑似反復なので主張に使わない。**
  **r < 0.49 なら「次元は疑似反復ではない」と書け、n=32 が使える。**
- **どちらも発火しない場合**は、**符号は 2 次元で正、n=32 の p を主張に使える**と書く。

**この回で撃たないこと**: D=5（キュー 2）、腕の作成、MC-ESO / NMMSO / `r3pso`、報告規則の振り直し。
