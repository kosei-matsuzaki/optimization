# その146 事前登録 —— キュー 1: 順位が入れ替わる `descent_budget` の水準を挟む

**書いた時刻: 2026-09-20 00:40 UTC（run の投入前。集計コードは 1 行も書いていない時点）。**

## 何を測るか

`Restart-Lander` の `descent_budget` を **3000** と **6000** にした 2 腕
（`Restart-Lander-3000` / `Restart-Lander-6000`、**`sigma_ratio=0.1` は据え置き**）を
**新 suite M01-M16（D=10、PIN01、正規予算 50 万評価、seed 0）で 1 本ずつ**回す（**新規 run は 32 本**）。

**変えたのは driver の `_METHODS` に 2 行足しただけ**（`scripts/niching_baseline.py`）。
`core/` は 1 ビットも触っていない。既存の `Restart-Lander` / `Restart-Lander-1540` の行も不変
＝ **記録済みの値は全部そのまま。** MC-ESO / NMMSO / RR-CMA-ES は回さない（保存値と対にする）。

## なぜ 3000 と 6000 か

その145 で **12500 → 1540 が Score 0.6284 → 0.3284** ＝ **直した NMMSO の 0.4144 を下回った**
（反証条件 (A1) の発火）。**順位が入れ替わる境界は 1540 と 12500 の間にある。**
**2 点だけ置いて境界を括る**（掃引ではない）。1540 / 3000 / 6000 / 12500 は概ね等比（×1.95 / ×2.0 / ×2.08）
＝ **4 水準で 8.1 倍を対数的に覆う。**

## 読み A（判定。先に書く側）

**量**: 16 問平均 Score（`eps_loose+dedup`、`r = 0.05 × span`、5 水準等重み ＝ その115 の合法な最良腕）。
**採点は `e115/analyze.py` の `rule_indices` / `score` / `aggregate` / `paired` / `mean_of` をそのまま import する。
新しい統計量は 1 つも定義しない。**

**関門（判定の前に通す）**: `e115/descents`（現行 null、seed 0）を同じ経路で再採点し、
**`e116/ranking_d10.csv` の `arm=legal` 行と 16 問 4 桁一致すること**（許容 5e-5）。外れたら判定に進まない。

**比較先（すべて既存の記録値。新しく測らない）**:
現行 null 12500 **0.6284**（その116）／ 1540 **0.3284**（その145）／ NMMSO **0.4144**（その139）／ MC-ESO **0.1385**（その116）。

**事前登録した予測**（その145 の機序 ＝ 「落ちるのは深さ側だけ」から出る。外れたら機序の側を疑う）:

- **1e-1 被覆は 4 水準ともほぼ横ばい**（1540 ですら null の 91.7%）。**3000 / 6000 の 1e-1 被覆は
  null の 90% 以上**に入る。ここが外れたら「広さは配置が作る」の読みを疑う。
- **動くのは 1e-5 側**。**深さ保持率（@1e-5 ÷ @1e-1）は 1540 の 0.186 と null の 0.850 の間で単調**。

**事前登録した反証条件**:

- **(B1) 3000 で既に 0.4144 を上回るなら、境界は 1540-3000 の間** ＝ **12500 は広い台地の内側**で、
  **「頭の結果はつまみの当たりではない」と書ける**（status.md の弱い環 1 が閉じる）。
- **(B2) 6000 でも 0.4144 を下回るなら、境界は 6000-12500 の間** ＝ **12500 は境界のすぐ上**で、
  **この場合は主張を書き換えず俯瞰に上げる**（論文に「降下予算への依存」を独立した節として書く必要が出る）。
- **(B1) も (B2) も不発なら**（3000 が下回り 6000 が上回る）、**境界は 3000-6000 の間**。
  **12500 は境界の 2.1-4.2 倍上** ＝ 台地の内側だが余裕は 1 桁無い、と量で書く。

**どちらでも書く 1 行**: **境界を挟んだ区間と、その区間が正規予算（50 万）の何分の 1 か。**

**副次（主張には使わない。符号と大きさを記録するだけ）**: 各腕 − 現行 null の対検定
（16 問、両側 Wilcoxon exact、`paired` をそのまま使う）。**これは「つまみが効かない」ことの主張ではない**
（効いてよい。問うているのは順位が動く水準はどこか）。

## 読み B（機序。追加評価ゼロ）

**量**: 降下ダンプからの被覆 `detected(ε) = |{land_opt : best_f ≤ ε}| / K` の水準別値
（**その113・その145 と同じ定義**）と、降下本数。
**比較先は保存物だけ**: 現行 null（`e115/descents`）、1540（`e145/descents.csv.gz`）、
MC-ESO（`e145/by_problem.csv` の控え ＝ その113 由来。`e113/hunts/` は その145 が削除済み）。

**この読みで見るもの**: **1e-1 被覆が予算に対して平らか**（＝ 広さは配置が作る）と、
**深さ保持率が予算に対して単調か**。**新しい統計量は定義しない。**
