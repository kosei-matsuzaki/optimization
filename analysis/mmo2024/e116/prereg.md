## 何を測るか

その115 が `Restart-Lander` で見つけた**合法な報告規則**を、**MC-ESO と NMMSO にも与えてから**
3 手法の MPR / mean-F1 / Score を読み直す。

合法な規則（その115 の最良腕。§5 で使ってよいのは D・探索域・評価予算・ε_tight=1e-5・ε_loose=1e-1 だけ）:

    reported = { f ≤ min(f) + 1e-1 の点を f 昇順に走査し、
                 既に採った点から距離 r = 0.05 × span(=10) 以内なら捨てる }

**K も f\* も使わない。** 現行の `max(100, 2K)` は K を使うので規則違反（その115 §a。ただし `cap100` と 16/16 同値）。

採点はその112・その115 と同一（`competition_setup_TR2024001.txt` §4）:
`PR(ε)=detected(ε)/K`、`precision(ε)=detected(ε)/n_reported`、`F1=2·PR·prec/(PR+prec)`、`Score=(PR+F1)/2`。
`detected` は**最近傍最適への帰属**（`core/runner.count_goptima_nn` と同順序）で数える。
集約は run → 問題 → 16 問平均、水準 1e-1..1e-5 は等重み。

## 条件

- **D=10・PIN01・M01-M16・正規予算**（`floor(50000·D)` = 50 万評価）・**seed 0 を 1 本ずつ**。
  seed 0 は e110（`Restart-Lander`）・e115（座標つき再 run）と同じ番号 ＝ **3 手法が同じ seed で対になる**。
- `Restart-Lander` は**回さない**。その115 の保存ダンプ（`e115/descents`、seed 0）をそのまま採点する
  ＝ **新規 run は 32 本（16 問 × 2 手法）だけ**。

  `scripts/niching_baseline.py` の `_dump_report_sets`（`REPORT_SET_DUMP` が立っているときだけ、
  各 run の**上限をかけていない**報告集合の `f` と座標を書き出す）だけ。案 (C)・方針欄 (1) と矛盾しない。
- **ダンプにオラクル列は置かない**（その115 の教訓の逆向き）。最近傍最適の帰属は解析時に
  `optima_pos` から計算し、**採点にだけ使う。規則の定義には使わない。**

## 事前登録した棄却条件（キュー 1 の原文をそのまま）

- **3 手法すべてに与えた後も `Restart-Lander` が Score で 2 手法に勝つ**
  → その112 の「null が公式指標でも 2 手法に勝つ」は**報告規則に依らない結論として確定**する。
- **順位が入れ替わる**（MC-ESO か NMMSO が `Restart-Lander` を Score で上回る）
  → その112 §3 の「MC-ESO が単独最下位」は**報告規則のアーティファクト**なので、
  status.md の該当行と「いま論文に書ける主張 3」を書き直す（**俯瞰へ上げる**。実行役は status.md を編集しない）。
- 検定は **16 問を対にした両側 Wilcoxon**（`method="exact"`）、効果量は rank-biserial。
  **腕ごとに `n_reported` を必ず併記する。**

## 何が出たら仮説が否定されるか

- 仮説は「**合法な報告規則の利得は手法非依存で、与え直しても 3 手法の順位は動かない**」。
- **否定される形**: 規則を与えたあとの Score で MC-ESO または NMMSO が `Restart-Lander` を上回る。
  そのときは**利得が手法依存**（報告集合の重複度が手法ごとに違う）ということで、
  **その112 の順位の主張は規則の選び方に載っていた**ことになる。
- **どちらに転んでも、その113 が測った被覆 2.80 倍・深さ 1.84 倍は 1 ビットも動かない**
  （あれは報告集合ではなく降下の被覆の測定）。

## コストと、枠に入らなかったときの打ち切り方

見積りは **MC-ESO 16 問 1 seed = 28 分**（その107）、**NMMSO 16 問 1 seed ≈ 15 分**（その109 の 2 seed 30 分の半分）
