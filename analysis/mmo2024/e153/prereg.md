## 3. 判定（事前登録）

**主判定 (i)**: **D=5 の 16 問対検定**（両側 Wilcoxon exact、**Score 主**、MPR と mean-F1 を内訳）。符号と p を書く。

**(ii)**: **公表最良 D=5（Score 0.7145）との差**を 2 手法それぞれで出す。
**RR 側は「公表最良の手法をこの harness で再現できているか」の照合**でもある（その149 の PIN02 と同じ役）。

**(iii)**: **D 間の差の相関** —— `Score(RL) − Score(RR)` の 16 問ベクトルを D=5 ↔ D=10、D=5 ↔ D=20 で相関させる。

**(iv)**: **3 次元の対差の並び**（D=5 / D=10 +0.0907 / D=20 −0.0071）を 1 つの表にする。

- **反証条件 (a)**: **D=5 でも符号が負（RR > RL）なら、頭の主張は「D=10 の 16 問で観測された現象」以上には書けない**
  （「D ≦ 10 で成立」とは書けない）。**その場合 status.md の書ける主張は全部その範囲に直す必要がある ＝ 俯瞰に上げる。**
- **反証条件 (b)**: **r(D=5, D=10) ≥ 0.4899（その149 の instance 間）なら、次元は D=5 でも疑似反復**
  ＝ その152 の結論（次元では n を増やせない）が 2 本目の次元対でも成立する。
  **r < 0.4899 なら「D=5 は D=20 より独立に近い」と書ける**（その場合でも n の合算はこの回では行わない。俯瞰の判断）。
- **反証条件 (c)**: **RL の D=5 Score が公表最良 0.7145 を 0.0066（1 seed の SD）より大きく下回るなら、
  「公表最良に勝つ／並ぶ」は D=10 限定の性質**であり、**D=5 では公表値との比較で負ける**と書く。
- **どれも発火しない場合**は、**符号は D ≦ 10 で正、しかも D=5 では公表最良にも並ぶ**と書ける。

**この回で撃たないこと**: 腕の作成、報告規則の振り直し、PIN02/PIN03、n の合算（プール）、
MC-ESO / NMMSO / `r3pso` / `NCDE`、`descent_budget` / `sigma_ratio` の再振り。
