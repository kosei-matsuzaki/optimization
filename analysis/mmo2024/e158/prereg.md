## 問い

その151（次元）・その155（c）・その157（instance）が 3 本の独立な経路から同じ一点を指した ——
**足りないのは降下の本数でも長さでもなく、1 本あたりの当たり率。** この量をまだ一度も分解していない。
**「届かない」のか「同じ所に何度も届く」のか。**

## 測るもの（3 分類）

1 run の降下を `descent` 昇順（＝ 発生順）に並べ、1 本ずつ次のいずれかに入れる。

- **(i) 初出ヒット**: `best_f <= ϵ` かつ その `land_opt` が **その run でそれまで一度もヒットしていない**。
- **(ii) 重複ヒット**: `best_f <= ϵ` だが その `land_opt` は **既出**。
- **(iii) 未到達**: `best_f > ϵ`。

**しきい値 ϵ は採点器と同じものを使う**（`e115/analyze.py` の `score` が使う `LEVELS`。
**距離の固定値は置かない** —— その76 の ρ 誤設定と同じ罠を踏まないため）。
**主水準は ϵ=1e-5**（`EPS_TIGHT`、競技仕様 §4 の目標精度で 5 水準の最厳）。
**感度として ϵ=1e-1（`EPS_LOOSE`）も全部併記する**（PR は 5 水準平均なので、片端だけでは読めない）。

**次元ごと・問題ごとに (i)(ii)(iii) の割合を出す。平均だけ出さない**（俯瞰の確認値が
「M01 は 122 降下中 115 ヒット・105 が既出、M03 は 0 ヒット」＝ 2 つの体制に割れている見込みを示している）。

## 検定

**16 問の対検定**（同じ問題を D 間で対にする。両側 Wilcoxon 符号順位・exact、α=0.05、効果量は rank-biserial）を
**D=5→10、D=10→20、D=5→20 の 3 対 × 3 分類**で回す。D=5 は PIN01（他次元と instance を揃えるため）を主とし、
**4 instance 平均を頑健性として併記する。**

## 副次（交絡の切り分け。事前に書く）

**重複は被覆が飽和すれば機械的に増える**（K 個しか無いので、K 個取り切れば以後のヒットは全部重複）。
したがって **「重複が増えた」だけでは律速が記憶だとは言えない。** 分離するために、
**クーポンコレクタ null** を置く: ヒット H 本が K 個の最適に**一様独立**に落ちるとき、
期待される相異なる数は `K(1-(1-1/K)^H)`。**観測の相異なる数 / この期待値**（＝ 集中度）を次元ごとに出す。
**この比が 1 に近いまま重複割合だけが上がるなら、重複は飽和の当然の帰結であって「同じ所に何度も届く」ではない。**
**比が次元とともに下がるなら、降下の落ち先そのものが偏っている ＝ 記憶が律速。**

**(iii) は `stop` 理由で内訳を出す**（`tolflatfitness` / `tolxstagnation` / `maxfevals` / `budget`）。

## 判定（この問いは分岐する）

- **(ii) 重複が支配して次元とともに増え、かつ集中度が下がる** → 律速は**記憶**。
  RR-CMA-ES が D=20 で追いつく機序の説明になる。**腕の置き場が出る（ただしこの回では腕を作らない。
  tabu / repel は arXiv 2405.01226 が占有しているので、手順 3 の 4 語彙を先に通すこと）。**
- **(iii) 未到達が支配して次元とともに増える** → 再起動一族は高次元で原理的に勝てない。
  論文は測り方の側に確定し、[status.md](../../../docs/status.md) の弱い環 2 は「もう腕は出ない」と書き切ってよい。

## 反証条件（事前登録。これが発火したら問いを畳んで俯瞰に上げる）

**(a) 3 分類の割合が D=5 と D=20 で<u>ほとんど動かない</u>** ——
**3 分類のいずれについても |D=5 と D=20 の問題対平均差| < 0.05 で、かつ 3 本とも α=0.05 で非有意**。
発火したら「1 本あたりの当たり率」という量が粗すぎるということなので、**この分解では説明できないと書いて畳む。**

**(b) 主水準 ϵ=1e-5 と感度水準 ϵ=1e-1 で支配する分類が入れ替わる** ——
発火したら**結論は水準依存**なので、どちらか一方で書かず「水準ごとに分ける」と書く。
