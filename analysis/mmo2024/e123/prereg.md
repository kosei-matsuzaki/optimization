## 判定量

問題 p ごとに、3×3 格子の MPR から 2 つの SD を出す（Score も必ず併記する）:

- **seed 間 SD** `s_seed(p)` = **インスタンス内の seed 間 SD をインスタンス 3 本でプールしたもの**（df = 3×2 = 6）。
- **インスタンス間 SD** `s_inst(p)` = **インスタンスごとの seed 平均 3 個の SD**（df = 2）。
- **比** `s_seed / s_inst` を**問題ごとに書き、6 問の中央値を主判定量にする。**

**注意（この比の偏り）**: `s_inst` は run のばらつきを含む（`Var(平均) = σ²_inst + σ²_seed/3`）ので、
**素の比と併せて、雑音を引いた `σ̂²_inst = max(0, s_inst² − s_seed²/3)` による比も必ず出す。**
**事前登録の判定は素の比で行う**（キュー本文の定義）が、**両方を記録する。**

## 追加の検定（事前登録）

比だけでは「インスタンス効果がゼロと区別できるか」が言えないので、以下も先に決めておく:

- **並べ替え検定（6 問まとめて）**: 問題ごとに 9 個の値を持ち、**問題内でインスタンスのラベルを並べ替えて**
  インスタンス間平方和 `SS_inst(p)` を再計算し、**6 問の和**を統計量にする（問題は block、問題間の水準差は入らない）。
  **20000 回、両側でなく上側**（インスタンス効果は SS を増やす向きにしか出ない）。
  **p < 0.05 なら「インスタンス効果は run のばらつきでは説明できない」、p ≥ 0.05 なら「区別できない」と書く。**
- **問題ごとの一元配置 F 検定**（3 群 × 3、df 2/6）も併記する。**6 問なので多重比較は Holm で補正する。**
- **その122 の seed 0 の値が 3 seed 平均からどれだけ外れるか**を問題 × インスタンスの 18 セルで出す
  （**その122 の問題別の表がどれくらい「1 seed の値」なのか**の直接の答えになる）。

## この測定を反証するもの（＝ 何が出たら結論を書けないか）

- **run のばらつきが純粋な雑音なら `s_inst ≈ s_seed/√3 = 0.577·s_seed` ＝ 比 1.73 が「インスタンス効果ゼロ」の予測値。**
  **比が 1.73 付近に出たら、上表の「0.7 以上」は「seed が主」ではなく「インスタンス効果が検出できない」と書くこと**
  （区別できないことと、無いことは違う）。
- **6 問はその122 で「動いた」問題として選んである** ＝ **`s_inst` が大きい側に選抜されている。**
  **この比を 16 問全体に外挿してはいけない**と結論に明記する。
- **途中打ち切りが起きた場合**、**6 run（3 インスタンス × 2 seed）が全部終わった問題だけを使う。**
  半端な問題は格子が欠けるので SD を出さない。**何問で出したかを必ず書く。**
