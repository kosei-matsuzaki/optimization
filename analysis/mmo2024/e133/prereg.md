## 判定（棄却条件。その125 と同じ形に保つ）

主判定量は **16 問平均 MPR**（キュー本文の指定）。**Score と mean-F1 を必ず併記する**（方針欄 2026-09-11 (1)）。

1. **`reseed` の 16 問平均 MPR < 0.5644**（現行 null）→ **再投入は一様再起動より悪い ＝ 路線を畳む。**
   **群 A（M01-M08）だけで見ても下がるなら完全に畳む。**
2. **群 A の 8 問で MPR が +0.10 以上** → **腕として意味がある**と書く。
3. **`bhop` が `reseed` と同等以上**（16 問平均 MPR の差が +0.02 未満、または対の Wilcoxon が非有意）
   → **腕としての主張は無い。**結果は「basin-hopping がこの suite で強い」という**測定**として書く。
4. **中間**なら群 A の利得と群 B の損失を別々に書いて比を記録する。
5. **`bhop` の報告点数が 2 桁に乗っていなければ、それはまだ basin-hopping を測っていない**（その125 の `bhop` は
   摂動幅 0 で報告点数 1.8 だった）。**そう書く。**

## 事前登録した予測 P1（キュー 3 本文 (b)(c)。交絡を外した形）

その125 の `reseed` の利得は **null が弱い問題に集中していた**（Spearman −0.666、並べ替え p=0.0061）。
ただしこの読みは 2 通りに交絡している —— **平均回帰**（1 seed・MPR は上に有界なので差は null と機械的に負の相関を持つ）と、
**「`ρ` が 0 でない」＝「着地が散っている」**（その125 で `ρ` が 0 でなかった 2 問 M06・M14 が利得順位のちょうど 1 位と 2 位）。

**交絡を外す**: **問題の順位づけを seed 1 の null で行い、差は seed 0 で測る。** 順位づけの変数が差と独立になるので平均回帰が消える。
**順位は run の前に凍結する**（後から選び直せないように、下に実値を書く）。

**2026-09-16 18:49 UTC に `analysis/mmo2024/e115/s1/descents` の 16 本を同じ合法規則で採点した seed 1 null の MPR（昇順）**:

- **P1 の予測**: **seed 1 での null の弱さ（昇順の順位）と、seed 0 で測った `reseed − null` の MPR 差の Spearman は負。**
- **P1 の反証**: **Spearman が 0 以上、または並べ替え検定（20000 回、両側）で p ≥ 0.05。**
- **P1 は副判定である**。主判定（上の 1-5）とは独立に報告し、**P1 が通っても腕の採否には使わない。**

## この仮説を反証するのは何か（明示）

仮説は「**推定量を直せば、自己情報だけで決めた中心と半径でもその121 の上限の利得が残る**」。
**反証は (a) 16 問平均 MPR が null の 0.5644 を下回ること、(b) 群 A の利得が +0.10 に届かないこと、
(c) `bhop` が `reseed` に劣らないこと**（(c) なら利得は「再投入」ではなく「摂動再起動一般」の性質で、この腕に固有の主張が無い）。
