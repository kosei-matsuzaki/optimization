e85 — 問い 1: F14-F20 の CF3 側（N16-CF3-5D / N18-CF3-10D）を 6 手法で採点し直す

背景（その83 で開いた穴）
  その73（N14/N16/N18）とその82（N15/N17/N19/N20）はどちらも MC-ESO と NMMSO の 2 手法だけの測定。
  その83 が N20-CF4-20D に残り 4 手法を足したところ、NCDE が同じセルで MC-ESO を有意に上回り
  （0.113 対 0.0625、p=0.0074）、「唯一の生きた候補」が消えた。同じ読み違いが CF3 側にも
  残っている可能性があるので、status.md の推奨 (A) の主柱である N16-CF3-5D（MC-ESO 0.653、
  公表最良 0.677 の 0.024 下）と N18-CF3-10D（被覆 6/6）から潰す。

設計（数値を見る前に固定した）
- 主測定: N16-CF3-5D / N18-CF3-10D（正規予算 4e5）を **追加 4 手法**
  （NCDE / r3pso / DE / NM-Restart）× **seed 0-11** で回し、
  e73 の MC-ESO / NMMSO の保存 CSV と **seed 番号で対にして 6 手法表**にする。
  seed 番号は --seed-offset により大域一意（seed i = optimiser seed i*100）なので paired のまま。
- 採点: --report-rule current（e73 / e82 / e83 と同じ）。判定水準は PR@1e-3 / 1e-5（その28 の運用規則）。
  PR@1e-1 は被覆の診断値としてのみ読む（順位の根拠にしない）。
- 分析: scripts/fullbudget_rank.py --pair MC-ESO,<other> を 4 回（新規スクリプトは書かない）。
  paired Wilcoxon（両側）・w/t/l・A12 を 5 水準すべてで印字する。
- NM-Restart は N06/N08 で restart 回数 1 の既知欠陥があるが（その28）、それは Shubert 固有なので
  ここでは落とさない。ただし n_reported を報告に添えて、同じ病理が出ていないか見る。

事前登録した棄却条件（問い 1 の本文どおり、数値を見る前に書いた）
  N16 / N18 で追加 4 手法のいずれも MC-ESO の判定水準（PR@1e-3 / 1e-5）を **有意に**上回らない
  ＝ CF3 側は 2 手法測定でも順位が正しかったことになり、推奨 (A) の主柱は残る。
  逆に 1 手法でも有意に上回れば、その73 の CF3 側の結論も N20 と同じ理由で崩れ、
  status.md の推奨 (A) は材料ごと作り直しになる（ゴール変更は俯瞰の仕事なのでここには書かない）。
