# 事前登録（数値を見る前に書いた。entry 95, 問い 2）

**仮説**: hill-valley 判定（公表最良 HillVallEA の機序）を `--null` に足すと、
その88・その89 が引いた「一様再起動 ＋ 局所降下」クラスの被覆上限が上がる。

**腕**（すべて replicate 単位で評価予算を揃える。1 replicate = suite の正規予算 1 本分）:

- `iso` — その88・その89 の null そのもの（一様抽出 → 等方 CMA 降下、1 降下 1499 評価上限）。
- `hv` — 一様に population を撒き、f 昇順に segment test で盆地分割し、各クラスタの
  leader から**クラスタ自身の分散を σ にして**降下する。test の評価もこの腕の予算から払う。
- `split` — `hv` の対照。test を「常に別盆地」に固定 ＝ **test 代を払わず、population の各点から
  局所 σ で降りるだけ**。「test が効いた」と「population から局所に降りたのが効いた」を分ける。

**主指標**: `cov_1e-05`（1 run で `best_f <= 1e-5` に到達した相異なる最適の数）。
replicate index で対にした Wilcoxon（α = 0.05）＋ A12。**水準は 1e-1〜1e-5 を全部併記する。**
帰属は その88 §2・その89 §5 の規則どおり **`best_f <= eps` で絞ってから最近傍**。

**この問いが指定した棄却条件（そのまま）**: hill-valley つきでも **N16 / N18 の最適 {2,3} が 0 本**なら、
被覆軸は F14-F20 で完全に閉じる。**逆に、上限が公表最良 `PR@1e-5` × K を超える関数が 1 つでも出たら、
そこだけを腕にする。**

**この測定を否定する結果**（仮説が偽と分かる形）: `hv − iso` の対差が全 4 関数で
**符号すら定まらない（w/t/l が拮抗し p > 0.05）**か、**負の側に有意**なら、hill-valley は
このクラスの被覆を買わない。

**恒等検査（記録との突き合わせ）**: `iso` 腕の `cov_1e-05` 平均は、その88 の表の
**N14 4.00 / N16 4.00 / N18 4.00** を再現するはず（同じ配分・同じ予算・同じ数え方）。
再現しなければ新しいコード経路の側を疑う。
