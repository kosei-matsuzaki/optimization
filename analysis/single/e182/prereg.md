## 問い（キューの原文どおり）

**学習 C の<u>サンプル飢餓</u>を直す —— rank-μ 更新の採用規則を「親に勝った close 子」から
「その世代の close 子の上位 μ」へ広げ、10D で測る。**

**病理の診断はこの研究が既に持っている** —— d20 で悪条件関数が 0% のままなのは、
学習 C の更新に使える成功サンプルが 1 世代あたり ~1 個で、EMA の実効記憶 1/c = 20 が次元に足りないため
（[history.md](../../../docs/history.md) 2026-08-29「伝播系統」）。
**この病理への手当ては 4 回試して 4 回とも落ちているが、4 件とも「少ないサンプルから多く搾る」側**
（順位重み付き rank-μ `cc_rank_weight` :1041 ／ 大域進化パス :865 ／ 系統パス `lineage_path_decay` :979 ／
学習率の引き下げ）**で、<u>本数は 1 度も動かしていない</u>。この回が動かすのはそこだけである。**

## 実装（腕 1 本。既定は 1 つも変えない）

`core/optimizers/mceso.py` の `_update_cc_cov` に **`cc_mu_frac`（既定 0.0 ＝ 従来規則）** を足した。
- **従来**: close 子 ＋ 配置成功 ＋ **`child_f < pf[k]`（親に勝つ）** の三重の絞り。
- **`cc_mu_frac > 0`**: 三重目を **「その世代の配置済み close 子を f 昇順に並べた上位 `ceil(cc_mu_frac × n)` 本」** に置き換える
  （CMA-ES の rank-μ の選択そのもの。本数を増やす側）。**選択だけを変え、y の作り方・重み・学習率・floor は 1 つも触っていない。**
- 腕の登録は `quick_check.py` の辞書に 3 行（`ccmu50` = 0.50 / `ccmu25` = 0.25 / `ccmu100` = 1.00）。**今回回すのは `ccmu50` だけ。**

**同時に片付けた死にコード（キューの指示）**: `_update_cc_cov` の `if False:` 進化パスブロック（中の `c1` が未定義で
有効化すると `NameError`）を削除し、**1 度も読まれない引数 `cc_rank1_weight` / `cc_path_decay` を落とした**
（[history.md](../../../docs/history.md):865 で大域進化パスは棄却済みなので**実装ではなく削除を選んだ**）。
状態フィールド `cc_path` とその初期化も同時に落とした。**削除したコメントにあった測定値 1 つは
ログに移した**（close-contact の成功ステップは **1 世代あたり 0.1-0.3 本**。これが飢餓の一次資料）。

### 実行上の逸脱（40 分枠に入れるため。値は変えていない）

**24 関数を 6 shard（4 関数ずつ、6 おきの交互配分）に分けて並列に走らせる**（その179 と同じ分割）。
`core/runner.py` が run ごとの seed を `seed=i*100`（run 番号だけ）で決めるので **分割は RNG 同一**。
`OMP_NUM_THREADS=1` 等を立てる。**n_runs・関数数・手法数・予算はどれも削っていない。**
`pynmmso` はこの image でビルドできないので **import だけ通る stub**（`Nmmso` を呼ぶと `RuntimeError`）を
`PYTHONPATH` に置いた。**NMMSO は 1 run も回さない。**

## 反証条件（キューの原文。数値を見る前に固定する）

- **(a) F07 と F12 がどちらも 0% のままなら、飢餓は原因ではない** ＝
  [status.md](../../../docs/status.md) の判断 (1) の撤退条件の 1 本目が消化される。**その 1 行を明記する。**

  次は 5D と μ 割の水準振り（`ccmu25` / `ccmu100` は登録済み）。
- **(c) 局所的に改善するのに全体が下がるなら**（4 件の棄却と同じ形）、それは
  **「本数を増やしても搾り方の問題が残る」ことの証拠なので、5 件目の棄却として記録し、軸を閉じる。**

**判定線を先に決める**（後付けを防ぐため）:
- **「0% を脱した」＝ SR@1e-10 が 20 run 中 1 本以上（≥ 5%）。**
- **「全体が下がらない」＝ 24 関数平均 SR@1e-10 が base（その179 の 36.46%、この回で再測する値）を下回らない**
  （**同一 run の base 行を対照にする。その179 の記録値は参考にしか使わない**）。
- **有意性は Wilcoxon（reference = MC-ESO、α=0.05）＋ A12 で読み、SR の差は関数別に列挙する。**
