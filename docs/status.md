## 確定した事実

- **報告軸は空**（その115・その116）。3 手法とも合法な規則で oracle 上限に厳密一致。**この軸にはもう 1 サイクルも使わない。**
- **後処理の利得は手法非依存ではない**（RL +0.2578 / MC-ESO +0.0720 / NMMSO +0.0278、3 組すべて有意）。
- **suite は最適の配置で半分に割れる**（群 A = PID 1-8 が 8/8 で過集中、群 B = PID 9-16 は 8/8 で一様と区別できない。その118）。**検定力の問題ではない**（K=10 に落として 200 回やり直しても 175-199/200 が有意）。
- **塊の成員は「使い切られている」のではなく「誰も届いていない」**（その119）。`enrichment` 成員 0.0770 対 孤立 1.1468（p=7.84e-20、≥1.0 は成員 0/55・孤立 82/185）。
- **盆地半径は最近傍最適までの距離 `NN` で決まる**（その121）。平均 NN は成員 3.616・孤立 7.770（比 2.15）で、**`r/NN` で層別すると 6 ビン全部で差が消える**（p = 0.169-0.876、A12 0.457-0.561）。
- **外した降下は迷子ではない** —— 着地点から最近傍最適までの距離は**中央値 0.000** ＝ **隣の最適に取られている。配分の問題であって降下の失敗ではない。**
- **局所 step-size の再スケーリングはこの設定では利得ゼロ**（`matched` σ0 の利得は r=0.1 で +0.273 だが **r=2.0 で +0.018、p=0.353**）＝ **効くのは降下の尺度ではなく始点の配置。**
- **MC-ESO の hunt の刻みは問題に依存しない**（segment 309-324 本・1 本 1539-1540 評価が K=10 でも K=20 でも同じ）。
- **問題別の不確かさは 2 seed 平均としてしか引用できない**（その110 の降下ブートストラップは seed 1 を 9/16 しか被覆しない）。
