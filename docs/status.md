1. **【首位】MC-ESO の部品 1 つを既存手法に移植した対照が、10D 以上で主指標を上回る。** `ctl_sepipop` ＝ IPOP-CMA-ES ＋ MC-ESO の分離性検査と座標走査。10D の CEC 順位 4.31 / 4.15 対 既定 4.62 / 4.75（2 run とも対照が上）、20D は 3.73 対 5.81。MC-ESO 本体が勝っているのは 5D（4.06 対 5.00）と、5D/10D の SR@1e-10 だけ。査読者の一言は「疫学の機構は『走査 ＋ IPOP-CMA-ES』に対して何を足しているのか」。**この対照の分解（走査を抜いた MC-ESO、素の IPOP）は未測定**（提案 3）。

4. 新規性の主張が細い。最も近い先行は EA4eig（CEC 2022 優勝、共有集団で 4 手法を併用）で、差は配分の決め方にほぼ限られる（[related_work.md](related_work.md)）。権威ある総説は判断 (3) のとおり未読。
5. **20D の hold-out が存在しない。** 20D の 3 run（j47・j51・j52）はすべて instance 1-5。判断 (2) の根拠になる「次元で向きが逆」自体が単一の instance 集合に乗っている（提案 2）。

## 次に測るべきものの提案（提案のみ。ジョブにするかは対話セッションが決める）

1. **2D の正準パネル（最優先、判断 (1) の歯止め）。** `--all --dim 2 --max-evals 5000`、instances 1-5 と 6-10（`--seed-offset 7`）、手法は j49 の 10 手法 ＋ `v4_pace`。2D は 5D より安いので 2 本で 20 分程度の見込み。得られるもの: 2D の CEC 順位の基準値（まだ 1 度も無い）と、`v4_pace` の 2D の歯止めの判定。**反証**: `v4_pace` の 2D の CEC 順位が既定より悪ければ、10-13 の規則で採用は止まる。
2. **20D の hold-out（弱い環 5）。** instances 6-10 ＋ `--seed-offset 7`、`--dim 20 --max-evals 50000`、手法は `MC-ESO,v4_pace,v4_small4,v4_grow8` ＋ j47 のパネル。**反証**: 20D の利得（CEC 順位 5.81→5.15〜5.27、`v4_pace` は 5.23）が再現しなければ、20D の逆転は instance の産物で、「育つ流行」の路線と判断 (2) の (b) は同時に閉じる。
3. **対照の分解（弱い環 1）。** 10D と 20D の各 1 run に 4 腕: `MC-ESO` / 走査を抜いた MC-ESO（`reassort_scan=0`）/ `ctl_sepipop` / 素の `IPOP-CMA-ES`。**反証**: 走査を抜いた MC-ESO が既定とほぼ同じで、かつ `ctl_sepipop` ≈ 素の IPOP なら、20D の赤字は走査ではなくチャネル側にある ＝ 20D は機構の作り直しが要る。逆に `ctl_sepipop` ≫ 素の IPOP なら、移植できる部品は走査であって、論文の寄与は「走査 ＋ 発火条件」に書き直すのが正直になる。
4. **（手法案、先行調査つき）宿主の数を次元ではなく測った原因で決める。** 20D の序盤の遅れの原因は記録では「16·D ＝ 320 個体では子の大半が親に勝ち、σ が上限付近に留まって集中が遅い」（10-15 `sigma_batch` の項）。j52 は次元で初期数を小さくして 20D だけ改善し 5D/10D を壊した。原因そのもの（親に勝つ子の割合）を見て縮めれば、次元ゲートを足さずに同じ場面だけ効く可能性がある。
   **先行調査（1 回の検索）**: 集団サイズを成功・停滞の信号で動かす系統は占有されている —— CMAES-APOP（中位値が区間で下がらないかを見て λ を調整、BBOB で評価済み）、LaPorte・Branke・Chen 2015（期待利得を最大化する親集団サイズ）、L-SHADE の線形集団縮小（LPSR）。ステップサイズ側の中位数成功則・PSR も近い。**「親に勝った子の割合で集団サイズを動かす」そのものは今回の検索では見つからなかったが、系統は埋まっているので新規性の主張には使えない。** 測った無駄の修理（実装詳細）として扱うのが正直で、採用しても論文の主張は増えない。**反証**: 20D の序盤（F01 の 2000 評価での log10 誤差。現状 0.8〜1.0、IPOP −4.3）が 2 桁改善せず、5D/10D が雑音の範囲に収まらなければ落とす。

率直に言うと、この週は手法が前に進んでいない。進んだのは測り方で、その結果として弱点が前よりはっきり見えた —— 5D は本当に 1 位、10D は主指標で 2 位、20D は自前の対照にも負ける。
いま決めるべきは次の腕ではなく、**判断 (1) の規則の優先順位と判断 (2) の射程**である。この 2 つが決まらないまま腕を足すと、今週と同じ「測ったが採否が書けない」が繰り返される。
