3. 候補の損は Gallagher（F21・F22）に集中し、主指標では見えにくい。10D 調整で F21 の SR が 100→75% 落ちても平均誤差の順位は上がる。査読者が関数別表を見れば必ず当たる場所で、論文では「弱構造の多峰を犠牲に悪条件の単峰を取る取引」と正直に書く必要がある。
