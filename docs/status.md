## 確定した事実

- **【新】記憶なし null は run になり、推定と一致した**（2 seed 0.5478 対 推定 0.5529、p=0.6685）。
  **seed は系統的な信号を運んでいない**（seed 間の対は −0.0256、5/6/5、p=0.4236）。
  **2 手法への 16/0/0 は seed 本数に依存しない。**
- **【新・計器の否定】その110 の降下ブートストラップ 95% 区間は、問題別の不確かさとして引用できない**
  （その111 で 2 本目の seed を当てると被覆 **9/16**、正直な区間なら約 15/16）。
  **幅が足りないのではなく中心が外れる** —— 平均幅 0.1419 に対し seed 間差は平均 0.0756・最大 0.3000。
  **＝ 論文の表に出せるのは 2 seed 平均の列だけ。seed 0 単独は M04 / M08 / M16 で 0.15-0.30 動く。**
- **【新】降下の 88% は上限 12500 に届く前に停滞判定で止まる**（`tolxstagnation` 44.7% /
  `tolflatfitness` 43.0%、1536 降下）＝ **「上限 12500」は降下長の記述ではない。**
- **【新】競技の Score は PR と static F1 の平均で、優勝手法は MPR では 2 位**（上表）。
- 新 suite で手元の 2 手法は互いに区別できない（p=0.9588）＝ **狭い支持集合は MC-ESO 固有の弱点ではない。**
  負け方は逆向き（NMMSO 広く浅く 17.7% ／ MC-ESO 狭く深い 35.2%）で、**oracle でも 0.1535。**
- `mpr_sup` は draw 本数の関数で収束していない（200 → 400 → 600 で 0.6287 → 0.6813 → 0.7119）
  ＝ **上限側の数字は必ず本数を添えて書く。**

## 次に効く一手

**キュー 1（既存 run に F1 と Score を計算して併記する。追加評価ゼロ）。** 理由: **いちばん弱い環 1。**
precision = 検出した最適数 ÷ 報告点数で、**両方とも保存済み**（MC-ESO その106 / NMMSO その109 /
`Restart-Lander` その110・その111）。**これが出るまで、null の「公表最良まで 0.090」も
「報告規則の項は空」も、半分しか確かめていない主張のままになる。**

**その次はキュー 2（4.5 倍の差の内訳 —— hunt 本数か、選抜か、降下か）。** 差の約 9 割は被覆側。
**計器の新規実装を含むので 1 サイクル丸ごと取ること**（その111 の実測）。

**率直に言えば、今回いちばん重いのは負の発見のほうだ** —— **20 サイクル積み上げた新 suite の
判定はすべて公式指標の半分の上に載っていた。** 符号（2 手法が null に全敗する）は F1 を足しても
まず動かない（precision は両者とも低い）が、**「null は公表最良に肉薄している」という位置づけは動きうる。**
**それが動くと、案 (C) が狙う「一族の外」の距離も、狙う機序も変わる。**
