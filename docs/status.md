## 確定した事実

- **報告軸は空**（その115・その116）。3 手法とも合法な規則で oracle 上限に厳密一致。**この軸にはもう 1 サイクルも使わない。**
- **PIN01 は 16 問平均としては代表的**（3 インスタンスで対にした Wilcoxon / Friedman が全部有意差なし、インスタンス間 SD は Score 0.0141）、**問題別の値としては代表的でない**（レンジ ≥0.10 が 6/16、最大 0.34）。その122。
- **問題別のばらつきは seed とインスタンスの両方から来る**（`s_seed` 0.0563 対 `s_inst` 0.0421。並べ替え検定 p=0.0321、Holm 後は 0/6）。その123・その124。
- **「1 seed でインスタンス間に差が見える」ことは、その問題にインスタンス効果がある証拠にならない**（その122 の選抜規則 対 3 seed の順位は Spearman +0.143、p=0.787）。その124。
- **suite は最適の配置で半分に割れる**（群 A = PID 1-8 が 8/8 で過集中、群 B は 8/8 で一様と区別できない。その118）。**検定力の問題ではない。**
- **塊の成員は「使い切られている」のではなく「誰も届いていない」**（その119）。**盆地半径は最近傍最適までの距離 `NN` で決まる**（その121）。
  **外した降下は迷子ではない** —— 着地点から最近傍最適までの距離は**中央値 0.000** ＝ **隣の最適に取られている。**
- **`Restart-Lander` の着地点は多重集合である**（その125、追加評価ゼロ）。**1 run の降下 95.2 本が落ちる先は相異なる点としては 29.3 個しかなく、降下の 62.3% は既存の着地と距離 1e-6 未満。**
- **間引き半径は recall を 1 ビットも落とさない**（その115）。**異なる最適どうしの最小距離は 32 run すべてで 4.26 以上**なのに対し、**掃いた半径は最大 1.0** ＝ 2 つの最適が同じ点に潰れる余地が構造的に無い。**動くのは precision だけ。**
