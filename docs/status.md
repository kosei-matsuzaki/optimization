## ユーザーの判断を仰ぐこと

**(1)【最重要・新規】案 (C) の結論は正しい。しかし記録されている理由は間違っている。追加 run ゼロで判明。**

方針欄は **「クラス上限が公表最良に届かないから一族の外に出る」**と書いている。だが
**その公表最良 0.651 を出している RR-CMA-ES は、その一族の一員である** ——
[de Nobel+ 2024, PPSN'24（arXiv 2405.01226）](https://arxiv.org/pdf/2405.01226) ＝
**再起動 CMA-ES ＋ tabu 点 ＋ hill-valley 判定**で、「一様再起動 ＋ 局所降下」に**再起動の記憶**を足しただけ。
**本プロジェクトはこの論文を「その22 の反発路線を占有する先行研究」として、
[related_work.md](related_work.md) は同じ論文を「公表最良の手法」として、別々に記録していた。**

その88 以降の「クラス上限」は **`repel` 記帳ゼロ ＝ 記憶なしの部分族**の上限である
（`analysis/mmo2024/e92/analyze.py` の定義）。同じ着地分布を**非復元抽出**（＝完全な冗長性回避）に替えると:

| D=10・16 問平均（500 draw、`analysis/mmo2024/e103/support_vs_draws.csv`） | 値 | 公表最良 0.651 との差 |
|---|---|---|
| `mpr`（記憶なし・n′ 本の i.i.d. 再起動） | **0.5530** | −0.098 |
| `mpr_earlystop`（同上、eps 到達で降下を打ち切る） | 0.6133 | −0.038 |
| `mpr_sup`（支持集合 ÷ K ＝ 完全な冗長性回避の理想値） | **0.7006** | **＋0.050** |

**予算が買う再起動本数 n′ は 43.8〜152.9 本**（`analysis/mmo2024/e94/ceiling_mpr_d10.csv` の `restarts` 列）、
**K は 10 か 20 ＝ 16 問すべてで n′ ≥ K。** よって完全な冗長性回避なら支持集合を全部拾えて 0.7006 に届く。
**＝「この一族では 0.651 に届かない」は成立しない。届かないのは記憶なしの部分族だけ。**

**それでも結論（一族の外に出る）は変わらない。理由が入れ替わる。** 損失を 2 つに分けると:

- **冗長性の損失 0.7006 − 0.5530 = 0.148** —— 同じ盆地を引き直す分。**公表最良 0.651 はこの区間の内側にあり、
  RR-CMA-ES はこの損失の約 3 分の 2（0.098 / 0.148 = 0.66）を既に回収している。**
  ＝ **一族に残って取れる余地は残り 3 分の 1（≈0.05）だけで、そこは公表最良が既に攻めている場所。**
- **到達可能性の損失 1 − 0.7006 = 0.299** —— 500 本撒いて 1 度も着地しない最適。
  **再起動の記憶ではこの 0.299 は 1 ビットも動かない**（tabu は支持集合を広げない）。**手つかずで大きいのはこちら。**

**仰ぎたい判断は 1 点**: 案 (C) を**この理由に置き換えて続ける**（推奨）でよいか。置き換えると狙う機序は
「クラスの外の何か」ではなく**「支持集合そのものを広げる ＝ 一様抽出＋等方降下では着地しない盆地に届く機序」**に
具体化される。方針欄の指示 3 に従って報告する。**こちらから MC-ESO には戻していない。**

**(2) 採用判断 6 件（c=1.0 / `_sig10` / `_fl08` / `soltrim_rho` / `commit_place` / 合成腕）が 38 サイクル滞留。**

## いま論文に書ける主張

**「既存手法より多く見つけた」は書けない。勝ちはゼロのまま**（2 集合・14 関数・6 手法で判定水準の首位ゼロ）。
**新 suite では勝ち負け以前に、まだ 1 度も手法を走らせていない。** 証拠が揃っているのは**計器**の側の 3 つ:

1. **再起動型 niching の PR は 被覆 × 報告 × 深さ の積に分解でき、各軸は独立に閉じられる**
   （N09 で予測 0.3541 対 実測 0.3549）。**弱点: 主要部が MC-ESO 1 手法の内部観察。**
2. **その21 の二分法（`reported ≈ min(distinct, deep)`）は手法をまたいで予言を出す**（律速側は手法 × 問題の組で決まる）。
3. **【新】多スタート族の予算損失を「冗長性 0.148」と「到達可能性 0.299」に分離して額を出せる**（上表、追加 run ゼロ）。
   **この形にすると公表最良の位置が読める** —— RR-CMA-ES は冗長性の 66% を回収した地点にいて、
   到達可能性には誰も触れていない。**弱点: null 1 本の上の計算で、手法側の実測が 1 つも無い。**

**文献側（今回 3 語彙。記録は research_loop.md の「占有されている領域」）**: **目的関数を deflate して同じ解に
戻れなくする路線は占有**（[arXiv 2107.13864 / Numerical Algorithms 2024](https://arxiv.org/html/2107.13864)、
continuation Newton ＋ deflation で臨界点を出し EA の初期種にする ＝ **8 件目**）。
**盆地ごとの予算配分（撤退候補 5 件目）に直接一致が出た**（[arXiv 2605.18351](https://arxiv.org/pdf/2605.18351) の
saliency-guided basin-wise budget allocation）。**GECCO 2025 の競技結果は公開されているものを見つけられなかった**

## 確定した事実

- **【新】予算が買う再起動本数は K を大きく上回る**（D=10 で n′ = 43.8〜152.9、K は 10 か 20）
  **＝ 記憶なし多スタートの損失は「本数が足りない」ではなく「同じ盆地を引き直す」。**
- **【新】`mpr_sup` は draw 本数の関数で収束していない**（200 → 400 → 600 で 0.6287 → 0.6813 → 0.7119、
  増分 +0.0525 → +0.0306、減速は対検定で有意でない p=0.3491）**＝ 上限側の数字は必ず本数を添えて書く。**
- **案 (C) の前提は主指標の側では 3 つの土俵（F14-F20 / 新 suite D=10 / D=20）で崩れなかった。**
  崩れたのは「上限」という語の適用範囲だけ（判断 (1)）。
- **深さの軸も報告の軸も閉じた**（c=1.0 で N08 の PR@1e-5 0.013 → 0.863 で代金ゼロ、N09 で `reported == visited` が
  15/15 seed）。**N07 / N09 の被覆天井 0.355 は 3 サイクル不動。hill-valley は被覆を 1 ビットも買わない**（その95）。
- **BBOB-24 dim2 の gate は「枯渇後だけを触る介入」に構造的に盲目**（例外は `soltrim_rho` の履歴一致）。
