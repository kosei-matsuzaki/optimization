## 確定した事実

- **報告軸は空**（その115・その116）。3 手法とも合法な規則で oracle 上限に厳密一致。**この軸にはもう 1 サイクルも使わない。**
- **自作の採点器は公表値を ±0.05 で再現する**（その127-129）。**書けるのはここまでで、「RR-CMA-ES の実力は 0.5377 である」とは書かない。**
- **seed のばらつきは手法によって桁が違う**（その129）。**RR-CMA-ES の 11 問平均 Score の n=3 SD は 0.0266、`Restart-Lander` は 0.0076 ＝ 3.5 倍差。**
  **機序は到達そのもの**（MPR と報告点数が同じ向きに動く）、**底上げではなく 2 問**（M10 が 1 seed で +0.36）。
  **＝ その128 の「seed ノイズ 0.006-0.014」は小さすぎた。公表値との残差 −0.03 は seed の幅と区別できない。**
- **PIN01 は 16 問平均としては代表的**（インスタンス間 SD は Score 0.0141）、**問題別の値としては代表的でない**（その122・その124）。
  **問題別のばらつきは seed とインスタンスの両方から来る**（`s_seed` 0.0563 対 `s_inst` 0.0421。Holm 後は 0/6）。その123・その124。
- **suite は最適の配置で半分に割れる**（群 A = PID 1-8 が 8/8 で過集中、群 B は 8/8 で一様と区別できない。その118）。
- **塊の成員は「使い切られている」のではなく「誰も届いていない」**（その119）。**盆地半径は `NN` で決まる**（その121）。
- **`Restart-Lander` の着地点は多重集合である**（その125）。**1 run の降下 95.2 本の落ちる先は相異なる点としては 29.3 個。**
- **間引き半径は recall を 1 ビットも落とさない**（その115）。**異なる最適どうしの最小距離は 32 run すべてで 4.26 以上、掃いた半径は最大 1.0** ＝ **動くのは precision だけ。**
