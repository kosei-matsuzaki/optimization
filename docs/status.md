## いちばん弱い環

1. **【首位・4 週連続】部品 1 つを既存手法に移植した対照が、いまだに 20D と 10D hold-out で主指標を上回る。** `ctl_sepipop` 3.73 対 4.15（20D）、4.15 対 4.46（10D hold-out）。査読者の一言は変わらず「疫学の機構は『走査 ＋ IPOP-CMA-ES』に対して何を足しているのか」。**この分解は 4 週続けて提案され、4 週続けて測られていない** —— その間に腕は 16 本測られた。今も最大の順序の誤りだと思う（判断 (4)）。

## 次に測るべきものの提案（提案のみ。ジョブにするかは対話セッションが決める）

1. **対照の分解（弱い環 1。4 週目の持ち越し。最優先に置くことを勧める）。** 10D と 20D の各 1 run に 4 腕: `MC-ESO` / 走査を抜いた `MC-ESO`（`reassort_scan=0`）/ `ctl_sepipop` / 素の `IPOP-CMA-ES`。**反証**: 走査を抜いた MC-ESO が既定とほぼ同じで、かつ `ctl_sepipop` ≈ 素の IPOP なら、20D の赤字は走査ではなく機構の側にある ＝ 手直しでは済まない。逆に `ctl_sepipop` ≫ 素の IPOP なら、論文の寄与は「走査 ＋ 発火条件」に書き直すのが正直になる。
2. **`wave_gen_floor` と素の λ を同じ run に並べる（弱い環 2。2 週目の持ち越し）。** 20D の調整と hold-out に `MC-ESO,ctl_plainwave,v5_wlamS,v5_wg15,v5_wg2` の 5 手法（j63 (h20) の実績で 1 本 25 分）。**反証**: 同じ run で `v5_wg15` − `ctl_plainwave` が 0.15 以内なら、20D の寄与は「波の λ を素に戻すこと」に尽き、`wave_gen_floor` の主張は「5D/10D を bit 一致で守る局在化」だけに縮める必要がある。0.15 を超えて下なら、予算から決める形そのものに利得があると言える。
3. **20D hold-out のパネル（弱い環 3 の半分）。** 比較 6 手法（RCMAES・LSHADE-SPACMA・IPOP-CMA-ES・EBOwithCMAR・L-SHADE・ELSHADE-SPACMA）を `--dim 20 --max-evals 50000 --instances 6-10 --seed-offset 7` で 1 本。**反証**: 既定の 20D 5 位が hold-out で崩れるなら、主張 1 の 20D の行は instance 1-5 限定と書き直すことになる。崩れなければ 2 週連続で再現した 44.2% を順位として書けるようになり、論文の 20D の節がそこで初めて成立する。
4. **波なしの ablation（安い。主張 7・弱い環 2 の裏取り。2 週目の持ち越し）。** 20D の 1 run に `MC-ESO` と `hd_wave_lambda=None`（既存の腕 `v4_native`）。**反証**: 波なしが 20D で既定と大差なければ、20D の議論はすべて波の外の話になり、提案 2 は要らなくなる。大きく落ちるなら、20D の成績は波が運んでいることが確定し、論文の 20D の節は「波の設計」として書くのが正直になる。
5. **g=1.5 の 5D（安い。判断 (1) の表の唯一の空欄）。** 5D の調整と hold-out に `MC-ESO,v5_wg15,v5_wg15cp` を 1 本（j61 (a) の実績で 2 設定 23 分）。**反証**: `v5_wg15` が 5D で既定と bit 一致しなければ λ の算術の読みが間違っていることになり、判断 (1) の表を書き直す。判断 (1) で (c) を選ぶ場合は `v5_wg15cp` の 5D が未測定なので必須。
6. **新しい腕は提案しない。** v5 は 4 ジョブで 16 腕を測り、採用候補は 1 つ。判断 (1) の返事と提案 1〜5 が済むまで、17 本目を測る理由が無い。

率直に言うと、今週は**性能の面では良い週**だった —— g=1.5 は 10D 以下を 1 セルも壊さずに 20D の SR@1e-10 を 37.1→43.5%（hold-out 44.2%）に上げ、Wilcoxon の実質的な敗けも無い。判断 (1) は前回より答えやすくなっている。
同時に、**研究としては 4 週間足踏みしている**。測定が動いたのは 1 週間で 5.8 時間、測った問いは 5 週続けて「波の λ」の 1 点だけで、その利得は素の λ の対照と主指標で区別できない（弱い環 2）。機構が何を足しているかを直接測る提案は 4 週続けて先送りされ、その間に対照 `ctl_sepipop` は 20D で 3.73 のまま誰にも抜かれていない。
いま要るのは 17 本目の腕ではなく、判断 (1) の 1 行と、提案 1・2 を次のキューに置く決定である。
