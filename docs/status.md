## ユーザーの判断を仰ぐこと

**(1)【新規】`wave_gen_floor` を既定に入れるか。入れるなら g=1 と g=2 のどちらか。**
停滞の波の λ を、波の予算で少なくとも g·D² 世代回せる大きさまで下げる規則（下限は CMA-ES の既定 4+⌊3 ln D⌋）。λ を次元ごとに手で決めるのではなく予算から出す式なので、10-14 の批評「次元の閾値は次元ごとの調整に見える」には当たらない。2500·D の予算では g=2 で 5D 20（＝既定と同値）・10D 31・20D 15、g=1 で 10D 62（上限で既定と同値）・20D 31。表は パネル CEC 順位（主指標、低い方が良い）/ SR@1e-10。j63。

|---|---|---|---|

## いちばん弱い環

1. **【首位・3 週連続】MC-ESO の部品 1 つを既存手法に移植した対照が、いまだに 20D と 10D hold-out で主指標を上回る。** `ctl_sepipop` 3.73 対 今週の最良の腕 4.12（20D）、4.15 対 4.46（10D hold-out）。査読者の一言は変わらず「疫学の機構は『走査 ＋ IPOP-CMA-ES』に対して何を足しているのか」。**この対照を分解する測定は 3 週続けて提案され、3 週続けて測られていない** —— その間に腕は 30 本以上測られた。これが今も最大の順序の誤りだと思う。
2. **20D の利得の出どころが「自分の設定の誤り」である疑いが強まった。** j61 で正しく測り直した対照 `ctl_plainwave`（すべての波を素の CMA-ES の λ で打つ）は 20D パネル **4.23**。今週の最良 `v5_wg2` は 4.12 で、差 0.11 は**この研究が使っている雑音の目安 0.15 の中**（別 run どうしの比較だが、どちらも同じ j47 パネルに当て、既定は bit 一致で再現している）。つまり 20D の改善の大半は「MC-ESO の波の λ=4·D が高次元で大きすぎた」の修理で説明でき、`wave_gen_floor` の寄与は「素の λ にすると壊れる 5D/10D を bit 一致で守れる」という**局在化の部分だけ**。論文ではここを正直に切り分ける必要がある（主張 8 の文献もこの読みを支持する）。
3. **15D と 20D hold-out に比較手法のパネルが無い。** 今週いちばん大きな数字（20D hold-out で既定 36.9% 対 腕 47.1%、15D で 51.7 対 55.0%）は run 内順位でしか並べられない。20D の比較 6 手法を instance 6-10 で回した記録は一度も無く、15D は今回が初回。
4. **09-27 の規則と 10-13 の主指標が、今週はじめて同じ腕の上で衝突した**（判断 (1)）。g=2 は主指標で最良だが 10D hold-out の SR を 1.9pt 下げる。どちらの規則を優先するかはユーザーの決定事項で、俯瞰の側では決められない。
5. 新規性の主張が細い（主張 8）。`wave_gen_floor` は既知の λ–η 軸の上の調整で、`recover_age`・`switch_pace`・`spill_keep`・`forecast_route` も個別には先行がある。主張できるのは組み合わせだけで、総説は 5 週目の未読（判断 (3)）。
6. 機構が次元で不活性になる形が増えた。`recover_age=50` は 2D で 1 セルも動かず、`wave_gen_floor` は g=1 なら 10D 以下で、g=2 なら 5D 以下で**完全に無効**（bit 一致）。式で決めているので「次元ごとの調整」ではないが、「低次元では提案の一部が存在しない」ことは関数別表と同じくらい確実に突かれる。
7. 記録の運用: `analysis/` が 1865 ファイル（規約 約 400）、`research_loop.md` が 330/300 行。**j63 の結果は作業ログにしかなく、history.md・findings.md に未反映**（history.md は j62 まで）。生データは片付けより速く増えている。

## 次に測るべきものの提案（提案のみ。ジョブにするかは対話セッションが決める）

1. **対照の分解（弱い環 1。3 週目の持ち越し。これを最優先に置くことを勧める）。** 10D と 20D の各 1 run に 4 腕: `MC-ESO` / 走査を抜いた `MC-ESO`（`reassort_scan=0`）/ `ctl_sepipop` / 素の `IPOP-CMA-ES`。**反証**: 走査を抜いた MC-ESO が既定とほぼ同じで、かつ `ctl_sepipop` ≈ 素の IPOP なら、20D の赤字は走査ではなく機構の側にある ＝ 手直しでは済まない。逆に `ctl_sepipop` ≫ 素の IPOP なら、論文の寄与は「走査 ＋ 発火条件」に書き直すのが正直になる。
2. **`wave_gen_floor` と素の λ を同じ run に並べる（弱い環 2）。** 20D の調整と hold-out に `MC-ESO,ctl_plainwave,v5_wlamS,v5_wg1,v5_wg2` の 5 手法（j63 (h20) の実績で 1 本 25 分）。**反証**: 同じ run で `v5_wg2` − `ctl_plainwave` が 0.15 以内なら、20D の寄与は「波の λ を素に戻すこと」に尽き、`wave_gen_floor` の主張は「5D/10D を bit 一致で守る局在化」だけに縮める必要がある（それでも書けるが、主題にはできない）。0.15 を超えて `v5_wg2` が下なら、予算から決める形そのものに利得があると言える。
3. **20D hold-out のパネル（弱い環 3）。** 比較 6 手法（RCMAES・LSHADE-SPACMA・IPOP-CMA-ES・EBOwithCMAR・L-SHADE・ELSHADE-SPACMA）を `--dim 20 --max-evals 50000 --instances 6-10 --seed-offset 7` で 1 本。**反証**: 既定の 20D 5 位が hold-out で崩れるなら、主張 1 の 20D の行は instance 1-5 限定と書き直すことになる。崩れなければ、今週の 47.1% を順位として書けるようになる（論文の 20D の節がここで初めて成立する）。
4. **波なしの ablation（安い。主張 7・弱い環 2 の裏取り）。** 20D の 1 run に `MC-ESO` と `hd_wave_lambda=None`（既存の腕 `v4_native`）。**反証**: 波なしが 20D で既定と大差なければ、20D の議論はすべて波の外の話になり、上の 2 は要らなくなる。大きく落ちるなら、20D の成績は波が運んでいることが確定し、論文の 20D の節は「波の設計」として書くのが正直になる。
5. **新しい腕は提案しない。** v5 は 3 本で 14 腕を測り、採用候補は 1 つ（判断 (1)）。判断 (1) の返事と提案 1〜4 の 4 本が済むまで、16 本目を測る理由が無い。

率直に言うと、今週は性能の数字がはっきり動いた週だった —— 20D の SR@1e-10 が 37.1 → 47.1% まで上がり、しかも hold-out で再現し、5D/10D を 1 セルも壊していない。
同時に、その利得の説明が弱くなった週でもある。素の CMA-ES の λ で波を打つだけの対照が 20D で 4.23 を出している以上、**今週の 4.12 は「新しい機構」ではなく「自分の設定の誤りの修理」として読まれる**。
いま要るのは 16 本目の腕ではなく、判断 (1) の 1 行と、上の提案 1・2 —— どちらも「MC-ESO の機構が何を足しているのか」を直接測るものである。
