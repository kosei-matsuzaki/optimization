## いま論文に書ける主張

**「既存手法より多く見つけた」は書けない。14 関数 × 6 手法で、判定水準で MC-ESO が首位の関数はゼロ。**
今回はさらに **F14-F20 では上限の側から勝てないことが確定した**（上記）。
証拠が揃っている主張は 2 つで、どちらも**手法ではなく計器**の側にある:

1. **再起動型 niching の PR は 被覆 × 報告 × 深さ に分解でき、各軸は独立に閉じられる**
   （その51・その55 / その60・その63 / その57・その62）。PR は天井と報告比の**積**（N09 で予測 0.3541 対
   実測 0.3549）。**弱点: 主要部が MC-ESO 1 手法の内部観察。**
2. **その21 の二分法（`reported ≈ min(distinct, deep)`）は手法をまたいで予言を出す**（その73 が初例、
   その82・その85 で 7 関数に拡大）。**律速側は手法の性質ではなく手法 × 問題の組で決まり**（N18 と N20 で
   MC-ESO の乗る側が逆）、**MC-ESO の被覆優位は深さに変換されない**（N18 は 1e-1 で 4 手法に 12/0/0 の首位なのに
   1e-3 で 5 分の 1）。**これが 1 を「単一手法の内部観察」から「診断法」へ上げる唯一の道。**

**文献側の注意（今回 3 語彙で確認）**: **その76 の ρ アーティファクト（10D では盆地の 1e-1 等高面が
ρ = 0.01 より桁で広く、採点器が同一盆地内の点を別 niche と数える）は単独では新規性にならない** ——
Parrott-Li 採点手続きの niche radius 依存性として既に主張されている
（[PMC11505590](https://pmc.ncbi.nlm.nih.gov/articles/PMC11505590/)、
[arXiv 2503.18066](https://arxiv.org/pdf/2503.18066)、[IEEE 5586085](https://ieeexplore.ieee.org/document/5586085/)）。
**計器としてだけ使う。** 「多様性 対 収束のトレードオフ」も教科書事項で、
[MCMC 側に mode coverage 診断がある](https://arxiv.org/pdf/2512.17977)。**査読者が最初に突くのはここ。**

## 確定した事実

- **【新】F14-F20 の 7 関数すべてで MC-ESO の被覆が公表最良を下回る**（上表、追加 run ゼロ）。
  **N18 の 1.000 は ρ アーティファクトで真値 0.667**（`PR == PRtrue` が eps ≤ 1e-2 で一致）。
  **【新・運用規則】F14-F20 型で腕を回すときはまず `PR@1e-1` を読む。公表最良を超えていなければ原理的に勝てない。**
- **深さの軸は閉じた**（c=1.0 で N08 の PR@1e-5 0.013 → 0.754、σ 解像度で 0.863、代金ゼロ）。**報告の軸も閉じた**
  （N09 で `reported == visited` が 15/15 seed）。**被覆の天井は N07 / N09 では出し切った**（0.355 が 3 サイクル不動）。
- **深さ調律 3 件は N18 で 1 ビットも動かない**（その74・その75）。動いたのは停滞カウンタの盆地相対化だけ
  （その77、0.167 → 0.292）で、**それは BBOB gate では等価交換**（その79）。
- **F11-F13 の headroom はゼロ。F11-F20 は既存依存の `ioh` で回せる**（その70）。
  **BBOB-24 dim2 の gate は「枯渇後だけを触る介入」に構造的に盲目**（例外は `soltrim_rho` の履歴一致）。
