## 確定した事実

- **報告軸は空**（その115・その116）。3 手法とも合法な規則で oracle 上限に厳密一致。**この軸にはもう 1 サイクルも使わない。**
- **後処理の利得は手法非依存ではない**（RL +0.2578 / MC-ESO +0.0720 / NMMSO +0.0278、3 組すべて有意）＝ **その28 の「全員が同じだけ上がる」はこの suite では成り立たない。**
- **現行 cap `max(100,2K)` が binding なのは MC-ESO だけ**（n_reported ちょうど 100.0）で、PR を 0.1075 → 0.1094 に落としていた。
- **`best_f` バイト一致ゲートは「発火しない」を意味しない**（その117）。`commit_place_r010` は **480 セル一致なのに 93 セル・195 回発火**、**初回逸脱が答えの確定より前だったセルは 0/93** ＝ 安全側だが根拠は「何もしない」ではない。
- **MC-ESO の hunt の刻みは問題に依存しない**（segment 309-324 本・1 本 1539-1540 評価が K=10 でも K=20 でも同じ）。
- 記憶なし null は run になり推定と一致（2 seed 0.5478 対 0.5529、p=0.6685）。**seed は系統的な信号を運んでいない。**
- **問題別の不確かさは 2 seed 平均としてしか引用できない**（その110 の降下ブートストラップは seed 1 を 9/16 しか被覆しない）。
