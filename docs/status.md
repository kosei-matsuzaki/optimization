## 確定した事実

- **報告軸は空**（その115・その116・その130）。**この軸にはもう 1 サイクルも使わない。**「RR-CMA-ES の実力は 0.5377 である」とは書かない。
- **seed のばらつきは手法によって桁が違う**（その129・その131）。**16 問平均 Score の n=3 SD は RR 0.0238、null 0.0066 ＝ 3.6 倍差。**
  **機序は到達そのもの**（MPR と報告点数が同じ向きに動く）、**底上げではなく 2 問**（M10 が 1 seed で +0.36）。
- **【今回】部分集合は中立ではない**（その131）。**11 問の差 +0.0902 に対し、埋めた 5 問は +0.0234。5 問で RR は −0.0284 しか落ちないのに null は −0.0953**（3.4 倍）
  ＝ **打ち切りで落ちた問題は「両手法に難しい」のではなく「片方にだけ難しい」ことがある。**
- **【今回】平均回帰は所見に化ける**（その133）。**その125 の Spearman −0.666 / p=0.0061 は、順位づけを独立な seed に移すと −0.428 / p=0.098 で通らない**
  （交絡つきなら −0.680 / p=0.0044 で再現）。**以後、「弱い側ほど伸びる」型の所見は順位づけを独立な標本から取ること。**
- **PIN01 は 16 問平均としては代表的**（インスタンス間 SD は Score 0.0141）、**問題別の値としては代表的でない**（その122・その124）。
- **suite は最適の配置で半分に割れる**（群 A = PID 1-8 が 8/8 で過集中、群 B は 8/8 で一様と区別できない。その118）。
- **塊の成員は「使い切られている」のではなく「誰も届いていない」**（その119）。**盆地半径は `NN` で決まる**（その121）。
- **間引き半径は recall を 1 ビットも落とさない**（その115・その130。損失は `r ≤ 0.2·span` の全域で厳密に 0.0000）。
