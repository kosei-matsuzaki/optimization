> 再起動型 niching の PR は、**深さ**（hunt の解放水準）・**報告**（f だけの trim が 2 段直列）・
> **被覆**（再起動の着地先分布）の 3 つで決まる。前 2 つは無償で閉じられる

## 確定した事実

- **正規予算では NMMSO がこの 7 関数を実質解く**（最小 0.984）。**1/10 予算の順位は正規予算に外挿できない**（その50）。
- **深さの軸は閉じた。** `hunt_level_tol` を採点精度で無次元化（`L = ε_target`）すると N08 の崖が消え
  （0.013 → 0.754、その51）、σ の解像度を足すと最後の 1 段も消える（→ 0.863、その55、代金ゼロ）。
- **報告の軸は閉じた。** f だけの trim が **2 段直列**（内部 `sol_archive` 容量 200 → 採点則 cap max(100,2K)）で、
  内側を niche 貪欲にすると N09 は被覆の天井にちょうど届く（0.173 → 0.274、その60）。
  **内側の改善が PR に出るのは報告点数が cap を下回っている間だけ**（K=36 では隠される）。
- **被覆の軸だけが開いている。** 律速は描画でも反発半径でもなく **再起動後の best-of-n_pop の選抜**（その22）で、
  正規予算でも同じ（その57・その58）。**予算は偏りを薄めない**（N07 は予算 10 倍で hunt 11 倍・被覆 2.0 倍）。
- **BBOB-24 dim2 の gate は「枯渇後だけを触る介入」に構造的に盲目**（その29・その33・その34）＝
  通ったこと自体は安全の証拠にならない（例外は `soltrim_rho`、その61）。
