4. 停滞の型を内部信号で見分けて別の手当てに振り分けられる。品質ゲート（best ≤ 1e-3·|f_init|）が Gallagher 型（1e-2 付近で止まる）と Schaffer 型（1e-6 付近で止まる）を分け、ゲート無しでは Gallagher が悪化する。（history 10-11）

## いちばん弱い環

1. **【首位】10D の利得の 8 割が「委譲」から来ており、委譲の正味が未測定である。** `w4q3E` の内訳は `fl10i` +0.84 → `w4q3` +2.09 → `w4q3E` +10.63pt で、最後の跳ね（+8.54pt）は残り予算の全部を白色化した `cma` の CMA-ES に渡す機構。改善した関数（F13 5→100、F12 0→55、F17 0→40）は**どれも CMA-ES 系が 100% を出している関数**である。査読者の一言は「これは MC-ESO ではなく CMA-ES のウォームスタートではないか」。**同じ切替点から素の CMA-ES を回した対照は 1 度も測っていない。**（提案 1）
2. 新既定も候補も、比較 5 手法と同じ run に並べていない。前回の見出し（包絡線への上乗せ）が取り下げになったのもこれが理由。（提案 2）
3. 新規性は「切替の引き金」1 点に細っている。委譲そのものの系統は占有済み（dynAS: Vermetten ら GECCO 2020、Kostovska ら PPSN 2022 ＝ CMA-ES の軌跡の特徴から学習済みモデルで 1 回交代。HCMA / ICMAES-ILS / LSHADE-SPACMA）。**今回 1 件検索した範囲では、学習共分散の条件数を引き金にする先行例は見つからなかった**（近いのは Vermetten らの CMA-ES 変種のオンライン選択で、引き金は条件数ではない。Shimizu & Toyoda は条件数を使うが用途は座標選択）。ただし権威ある総説は判断 (3) のとおり未読なので、「新規」とは書かない。参考: Vermetten ら自身が「切替の予測利得は実装すると出ない」と報告している ＝ 利得が出ている事実自体は主張になりうる。

## 次に測るべきものの提案（提案のみ。ジョブにするかは対話セッションが決める）

1. **委譲の正味を測る（最優先、弱い環 1）。** 10D 1 本の run に 4 腕: 現既定 / `v1_w4q3` / `v1_w4q3E` / **委譲の対照**（同じ引き金の時点で、白色化も MC-ESO の状態も使わず、最良点から素の CMA-ES を σ0 既定で残り予算まで回す）。反証: 対照が 52.71% の −2pt 以内に入るなら、引き金・白色化・内部状態のどれも効いていない ＝ 機構としての主張は落とし、「MC-ESO は CMA-ES の良い初期点を作る」という別の主張に書き換える。
2. **新しい基準 run（弱い環 2）。** 候補 ＋ 現既定 ＋ 比較 5 手法を 1 run で 2D / 5D / 10D。得られるもの: run をまたがない順位、包絡線への上乗せの再測定、主張 6 の決着。反証: 10D の上乗せが +0.00pt のままなら、+10.63pt でも「比較手法の集合に覆われている」は生き残る ＝ 論文の主張は順位ではなく別の軸に置く必要がある。
3. **委譲の 2 つの半分を分ける。** j29 は `wave_use_C`（白色化）と `wave_ill_handover`（引き金 ＋ 全予算）を**まとめた形しか正準で測っていない**（ローカルでは C 単独 10D 44.6、H 51.9、E 53.1）。10D で C 単独・E を並べる。反証: C 単独が 10D の利得の半分以上を出すなら、主張は「引き金」ではなく「白色化」になる ＝ 新規性の置き場が変わる。
4. **5D の残り赤字。** 候補は 5D で CEC 系の勝者に 6.25pt 下。5D での委譲の寄与は +1.04pt しかない（10D は +8.54pt）。5D の追跡を取って、委譲が 5D で効かない理由（学習共分散が悪条件にならない／引き金が遅い）を切り分ける。反証: 5D で引き金が発火していないなら、閾値は次元で変える対象になる。

率直に言うと、この 2 週間で見通しは良くなった。前回の「上乗せ +0.00pt ＝ 独自性が仕事をしていない」から、比較 5 手法に 3 次元で勝つ候補まで来ている。
ただし利得の出どころは MC-ESO 固有の部分ではなく、終盤を既存の CMA-ES に渡す判断である。**提案 1 を先に通すことを勧める。** 通らないまま採用すると、査読者の最初の一言に答えられない状態で既定が確定する。
