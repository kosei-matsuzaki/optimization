## 確定した事実

- **差は Vincent だけで作られている**（判定水準で 96%）。Vincent は**被覆律速**、Shubert は**深さ律速**。
  `reported ≈ min(distinct hunts, deep hunts)`。
- **深さを止めていたのは `hunt_level_tol`**（`mceso.py:919-928`）。実効水準 `tol × f_init_scale` の
  `f_init_scale` が次元で 17 倍動くので、**無次元係数 1 個で両次元を吸収できる**。
- **被覆を止めているのは描画でも反発半径でもなく再起動後の選抜**（その22）。描画は N07 の 36 解全部に
  触れているのに、μ+λ 貪欲の best-of-20 が広い盆地を選び、着地は 11/36。
- **報告規則では差は埋まらない**（その28、7 手法）。利得は全手法で 1e-1 に集中し ε≤1e-3 で順位が動かない。
- **BBOB-24 dim2 の gate は「枯渇後だけを触る介入」に構造的に盲目**（その29・その33・その34）。
  分岐は常に `best_f` 確定後 ＝ **通ったこと自体は安全の証拠にならない**（内訳を測ること）。
- **NM-Restart の Shubert 行は無効**（restart 回数 1。`_XATOL=1e-12` で simplex が収束しない）。
