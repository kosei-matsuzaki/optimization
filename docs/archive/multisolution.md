## 1. 何の路線だったか

ゴール文（停止時点）: 「多峰度の高い問題（大域最適が多い問題）で、既存手法より多くの大域最適を見つける。」
多様性の定義は分野標準の「精度 ε 以内で発見された相異なる大域最適の数」で、自作の定義は使わない。

時期:
- 前段の監査テーマ「受容集合トポロジー／多様解の監査」は 2026-09-01 開始、2026-09-02 に新規測定を止めた。
- 多峰テーマは 2026-09-02 に確定事項を集約（作業ログ その15〜）し、2026-09-27 の その176 が最後の測定。その177 から単一解テーマ。

主指標の変遷:
- 当初は CEC2013 niching の peak ratio（ε = 1e-1〜1e-5）。手法の判定は ε ≤ 1e-3（その28。1e-1 は報告規則の質を測ってしまい識別力が無い）。対象は N04-N10、その70 以降は合成関数 N11-N20 にも広げた。
- 2026-09-08 のユーザー決定で GECCO 2024/2025 競技の新 suite（Ahrari+ の 16 問 M01-M16、D=5/10/20、正規予算 `50000·D`、K は PID 1-8（群 A）が 20、PID 9-16（群 B）が 10）を追加した。CEC2013 は公表値と比べられる共通土俵として維持（置換ではない）。
- 2026-09-11 のユーザー決定で新 suite の判定を競技の公式 Score ＝ (PR + static F1)/2 の 5 水準平均に揃えた。MPR と mean-F1 を内訳として必ず併記する。F1 の分母は報告点数。
- `PRtrue`（最近傍帰属で数え直した PR）は自作の診断値で、判定には使わない（その76）。

比較手法:
- 出発点（その15）: NMMSO / NCDE / Crowding-DE / r3pso / NM-Restart / MC-ESO。首位は NMMSO。
- 2026-09-08 の案 (C) で「MC-ESO の変種を新しく作らない」と決め、以後 MC-ESO は比較対象の側に置いた。
- 追加した対照: 記憶なし多スタート `Restart-Lander`（`core/optimizers/restart_lander.py`。箱から一様に 1 点 → 等方 CMA 降下 → best 点を報告集合に積む、を予算まで繰り返す。記憶・反発・選抜なし。その110）、競技次点 RR-CMA-ES（著者が `modcma` に入れた repelling 機構。その127）、素の basin-hopping（その133）。
- 公表値の出典は GECCO'2024 の結果資料 1 本（D=10 の公表最良 MPR 0.651 は RR-CMA-ES、Score の優勝は TRDE-LR 0.6080）。

止めた理由: 2026-09-27 のユーザー決定（`research_loop.md` 方針欄の最上段）が主テーマを「MC-ESO が 1 つの最適解をどれだけ精度よく速く見つけるか」に切り替え、「多解（niching / peak ratio）の路線は一時停止する。キューから外し、新しい測定も論文化の作業もしない」「後で論文化・再開できる形で置いておく」とした。同時に 09-08 / 09-11 の指示のうち新 suite・CEC2013・Score・peak ratio に関するものは、再開まで効力を止めた。直前の状況は、案 (C) の根拠だった「一族の被覆上限」が計器の誤りとして消え（その171〜その174）、この研究が作った手法で勝った結果はゼロ、新規性の置き場は測定の側だけ、というものだった。

## 2. 確定した結論

各項の末尾がサイクル番号。後で書き換えられた記述は 2.7 にまとめ、ここには訂正後の読みだけを書く。

### 2.1 前段: 受容集合と多様解の監査（2026-09-01〜09-02）

- 多解手法の報告集合は、未定式化基準のもとで「上位 K を報告する」に勝ち越さない。
- 結論はシナリオモデルで反転する。モデルごとに採点される性質が違う（instance = 解の数、constraint = 空間的な広がり、tilt = 何も効かない）。「たくさん返す」ことはどのモデルでも効かない。
- 受容集合が単一の塊の関数では、どの選択規則も上位 K に勝てない（11 関数すべて A12=0.50）。断片化は「幾何が効くか」を決めるが「数か距離か」は決めない。
- 脆さの原因は受理規則。親比較を最近傍置換にすると劣化 −13 → −2、ただし深さが 100% → 0%。1 つのつまみで深さと広さは両立しない。
- 損失の正体は全滅。全滅率は spread が決める（ρ ≈ −0.9、24/24、次元 2/3/5 で不変、領域サイズにも不変）。
- 品質帯 τ=0.1 は 3 モデルすべてで安全だが、安全な設定と効果の大きい設定は別。後処理としては一律に効かない。
- 空振り（規則が上位 K に落ちること）は検出力の損失ではなく暗黙のヘッジ。安全性を担うのは候補数ではなく帯幅の上限。
- 多峰テーマへ引き継いだ 1 点: MC-ESO は次元が上がると報告集合が縮む（cut 0.25 での spread 0.176 → 0.139 → 0.117、dim 2/3/5）。他の 8 系列は全部広がる。
- テーマを止めた理由は失敗ではなく射程（監査の量は peak ratio に効かない）と、報告規則を設計対象にする路線の先行占有（HVPI / F 値、Dynamic F1、persistence-guided basin decoding）。

### 2.2 CEC2013 N04-N10 での機序（その15〜その69）

注意: その15〜その48 は正規予算の 1/10 で、その50 が「1/10 予算の順位は正規予算に外挿できない」を実測している。この期間から順位は引かない（機序の主張は生きている）。

- 出発点の順位は NMMSO 0.763、MC-ESO 0.557 で 2 位。差はほぼ Vincent（N07 / N09）で作られている。（その15）
- PR は evals/K でも K でも決まらない。分けているのは予算を新しい最適解に変換し続けられるか（予算応答）。r3pso は完全に飽和、MC-ESO は高 K でだけ飽和、NMMSO だけが高 K でも変換し続ける。（その17）
- hunt 単位で見ると reported ≈ min(distinct hunts, deep hunts)。Vincent は被覆側、Shubert は深さ側が律速。（その21）
- 再起動の被覆を決めているのは描画ではなく選抜（best-of-20 が広い盆地の点を選ぶ）。反発半径の適応は 0.24 → 0.27（要 0.50）で効かない。（その22）
- σ のスケールと受理規則という無関係な 2 介入が同じ「深さ↔広さ」の線の上を動く。crowding は広さを買い、深さで払う。（その29）
- Shubert の深さを止めていたのは `hunt_level_tol`。解放水準が採点閾値 1e-3 と 1e-5 の間に落ちていた。1e-8 にすると N06 の PR@1e-5 が 0.17 → 0.76。ただし解放水準は `tol × f_init_scale` で次元により 17 倍動くので、固定値の掃引は無意味で eps 相対の形で扱う。（その30・その35）
- BBOB-24 dim2 / 5000 評価の gate は「枯渇後だけを触る介入」に構造的に盲目。120 run で `post_gain > 0` がゼロ。同点には (a) 未発火 / (b) 発火したが同じ / (c) 分岐が答えの確定後、の 3 種があり、安全の証拠は (b) だけ。（その29・その33・その34）
- N08 の残段は σ の解像度で決まっていた。`sigma_floor_ratio` 1e-6 → 1e-8 で段が 15/15 seed から消え、代金ゼロ。（その54・その55）
- 正規予算では 3 段構造（被覆の天井 / 内部 archive の f だけの trim / 採点則の cap）。N09 の PR@1e-5 は内部 trim を niche 貪欲にして 0.173 → 0.274、`commit_place` と重ねて 0.173 → 0.355 ＝ 天井と同値。天井と報告は独立な 2 因子で、PR はその積。（その57・その58・その60・その63）
- 幅比例（広い盆地に着地が偏る）は 4 手法すべてに出る。一様撒きの体積比例 null で幅上位 1/4 が箱の 81.4%、MC-ESO は 98.0%、NMMSO は 41.9%。「best-of-n クラスの性質」という主張は棄却。（その64）
- 公式採点器（`how_many_goptima`）は真の最適の位置を見ないので、10D では同じ盆地の点が ρ を越えて散らばり別 niche と数えられる。N18-CF3-10D の `PR@1e-1 = 1.000` は真の被覆 4/6。比較（順位）は公平だが、機序の主張には使えない。（その76）
- BBOB gate を通した採用候補 6 件（c=1.0 / `_sig10` / `_fl08` / `soltrim_rho` / `commit_place` / 合成腕）は 2026-09-18 の俯瞰が全件不採用で閉じた。MC-ESO の既定は 1 つも変えていない。（その117）

### 2.3 CEC2013 F11-F20（案 (A)、その70〜その95）

- F11-F20 は `ioh` にデータファイル無しで入っていた。`core/` 無変更で動く。（その70）
- F14-F20 の 7 関数を 6 手法で採点し直すと、MC-ESO が判定水準で首位に立つ関数は 1 つも無い。採用候補を全部積んだ腕も CF3 の 2 関数で被覆を 1 ビットも動かさない。案 (A) は算術でも実測でも閉じた。（その85・その86）
- 「A だけが届く」を 2 手法の対で書かない。N20-CF4-20D の MC-ESO の勝ちは、残り 4 手法を足すと NCDE が有意に上回った（PR@1e-5 0.113 対 0.0625、30 seed、2/16/12、p=0.0074）。（その82・その83）
- 異方な共分散の降下は深さと安さを買うが、被覆は買わない。（その89）
- hill-valley 判定は被覆を買わない。効いていたのは判定の副産物の歩幅で、その利得は +1.58 の 2D → +0.33 の 3D → 0.00 の 5D / 10D。被覆軸は F14-F20 で閉じた。（その95）

### 2.4 GECCO 2024/2025 suite（その91〜その176）

- 問題ごとの公表値は存在しない。比べられるのは「D 別・16 問平均」1 段だけ。手法論文の自己申告値は競技の測定値と桁で食い違う（N-DAM-CMA-ES は 0.6055 対 0.057）。（その92）
- MC-ESO は D=10 で記憶なし null に 16 問全敗（0.1021 対 0.5529、0/16/0、p = 3.05e-5）。（その106）
- その null を run にすると 0.5606（推定 0.5529 の裏が取れた）。以後これを `Restart-Lander` と呼ぶ。（その110）
- 競技の Score で採点し直しても順位は同じ（RL 0.3639 / NMMSO 0.1211 / MC-ESO 0.0638。報告規則は当時の既定）。（その112）
- MC-ESO は null の 130 倍撒いて、触れた盆地は 0.54 倍。「撒き方を変える」型はこの suite で否定されている。（その113）
- 合法な報告規則（ε_loose の足切り ＋ 座標の最小間隔で間引き）は oracle 上限に 16/16 で一致する。ただし利得は手法依存（RL +0.2578 / MC-ESO +0.0720 / NMMSO +0.0278）で、上限は手法自身の recall が決める（F1 の天井 2·PR/(1+PR)）。後処理は公平化の道具ではない。（その115・その116）
- 最適の配置の構造は取りこぼしを説明しない（ρ=−0.091 / p=0.737）。（その118）
- 競技次点 RR-CMA-ES を同じ採点器に載せると 0.5377（公表 0.5730 との差 −0.0353）＝ 採点器の妥当性が第三者手法で確認できた。（その127）
- RL 対 RR-CMA-ES（D=10）は 16 問 × 3 seed 平均で +0.0694、11 勝 0 分 5 敗、p=0.07391 ＝ 向きは正だが Score では有意でない。単独で通るのは seed 0 の 1 本だけ。（その131）
- 素の basin-hopping は 16/16 で負ける（MPR −0.2913、p=3.052e-5）。強いのは摂動つき再起動一般ではなく記憶を持たない多スタートそのもの。（その133）
- 頭の主張（本物の niching 手法が記憶なし多スタートに負ける、D=10）: NMMSO を公表設定に直した後でも 16 問平均で null が +0.2140、12/0/4、p=0.004181。NCDE / r3pso も 16/16 で負け、公表帯の `r3pso-p400` も 0.3341 で 16/0/0。手法軸は n=4。（その139・その140・その143）
- 勝っている null のつまみは効く。`descent_budget` を 12500 から 1540 に下げると Score 0.6284 → 0.3284 で NMMSO 0.4144 を下回る。交差点は 1540 < X < 2200 で、既定 12500 はその下限の 8.1 倍上。`sigma_ratio` は 0.05 / 0.1 / 0.2 で Score 0.5857-0.6284。（その145〜その148）
- instance・次元・seed は疑似反復で、独立な n を増やさない（instance 間の差の相関 r=+0.49、次元間 r=+0.6238）。プールした検定は主張に使わない。（その149・その152）
- D=20 では RL 0.4504 と公表最良 0.4445 は「並ぶ」（差は seed ばらつきより小さい）。RR-CMA-ES 0.4575 対 RL 0.4504 は p=0.6698 で差が消える。（その151・その152）
- 負けの内訳: 大域最適に届いた降下のうち既出の最適に落ちる割合が D=5 82.6% / D=10 85.3% / D=20 92.3%。重複は飽和の帰結ではない（集中度が 0.7143 → 0.5439 → 0.3590 と落ちる）。（その158）
- 降下長は D=20 でだけ binding（2 倍で +0.0418、p=0.03125。打ち切り率は D=5 で 5.8%、D=10 で 11.0%、D=20 で 24.3%）。軸は 25000 で飽和し、16 問平均の飽和は K=20 −0.0128 と K=10 +0.0230 の相殺だった。K 依存はその165 の新規データで再現しなかった（7/7 → 4/6）。（その163〜その165）
- CEC2013 では RL − NMMSO の符号が D≧3 で新 suite と一致し、D=2 で反転する（D≧3 の 7 問 MPR +0.0762、3/3/1、有効対 4、最小達成可能 p が 0.125 ＝ 設計上有意にならない。D=2 の 3 問 −0.3472）。10 問平均の帰無はこの相殺。（その166・その169、その174 で比較相手を直した読み）
- CF3 の取りこぼし 2 解のうち 1 解は報告規則。RL は D=2/3 で `f ≤ 1e-5` の 5 解に到達しているのに、`max(100, 2K)` の best-by-f 切りで自分の重複が当たりを押し出して 4.00 になる。間引きを挟むと D=2 は 4.00 → 5.00、D=3 は 4.67、半径を 4 桁振っても不変。最適 {3} だけが本物の被覆の穴。（その170）
- RL 対 NMMSO の margin は新 suite の中で次元に対して単調に増える: D=5 +0.0407（7/1/8、p=0.7197。中央値は負で頑健でない）、D=10 +0.2140、D=20 +0.3068（16/0/0、p=3.05176e-05）。margin を作っているのは RL の強さではなく NMMSO の落ち方（D=5 → D=20 で RL −0.3266、NMMSO −0.5929）。D=20 の NMMSO は点を出さないのではなく、出した点が自分の最良の 1e-1 以内に入っていない。この節が支えるのは「範囲」であって「勝ち」ではない。（その175・その176）

### 2.5 独立に書ける方法論ノート 3 本（`status.md` 2026-09-28 版の 7〜9）

1. 外部実装は論文の実験節と 1 行ずつ照合する（NMMSO +0.2596 / `r3pso` +0.1873）。欠陥は実在して大きいのに判定を 1 問も動かさない。NMMSO の欠陥は `swarm_size` の直書き 10 が公表設定 `10·D` の 1/10 だったこと（N19 0.106 → 0.350、公表 0.443）。低次元での一致は高次元の配線の証拠にならない。（その136・その137・その143）
2. GECCO niching 競技の公式 Score は harness をまたいで比較できない。同一手法（RR-CMA-ES）・同一公表設定で MPR −0.09〜−0.19、mean-F1 +0.12〜+0.20。報告点数（MPR は報告点数に対して平ら）・被覆係数 c と再起動本数・instance・検出規則（現行採点器は既にいちばん甘い規則と 640/640 で一致）の 5 軸すべてで説明できなかった。残るのは「公表値を出した提出配線が別物」だけで、その設定は手元のどの文書にも無い。（その154〜その160）
3. 負けの内訳は「届かない」ではなく「同じ所に何度も届く」（重複率 D=5 82.6% / D=10 85.3% / D=20 92.3%）＋ 公式の報告規則が重複の多い手法から本物の当たりを取り落とす（CF3 で 4.00 → 5.00）。（その158 / その170）

### 2.6 テーマを越えて有効な測定上の教訓（抜粋）

全文は退避元の「測定上の教訓」節（タグ側 `acceptance_topology.md` の 1139 行付近と 13776 行以降）。再開時に最初に効くものだけ挙げる。
- 関数をまたいで相関をプールしない。単一 seed で結論を出さない。定義を変えたら結果がどう動くかを測る（定義依存性は報告事項）。
- 恒等式で分解できる指標（PR = 被覆 − 報告損失）は成分を常に並べて印字する。事前予言は合成指標ではなく成分の上に登録する。（その80・その81）
- 手法非依存に当てられる介入（報告規則・後処理）は 1 手法で測ると必ず効いて見える。他手法にも与えてから読む。（その20 対 その28、その116）
- 「A が最良」「A だけが届く」は比較対象を全部回すまで書かない。（その83）
- 「弱い問題ほど腕が効く」型の主張は、順位づけを差と独立な seed から取る（同じ run だと平均回帰だけで出る）。（その133）
- 自作の測定環境の妥当性は、公表値のある他者の手法を公表値の許容幅で再現できることでしか示せない。（その127）
- 1 seed のスクリーンは所要の見積りにしか使わない。スクリーンの壁時計も下限。（その135・その142）
- 有効 n の下限は問題数ではなく指標の刻みと K で決まる。同点の多い対検定は p の隣に有効 n を書く。（その163・その166）
- 飽和で軸を閉じる前に、事前登録した層別（K の群）で符号を見る。平均が動かないには「どこも動かない」と「逆向きに同じだけ動く」の 2 種がある。（その164）
- つまみの掃引結果は「どの次元・どの suite で振ったか」を結論文に書き込む。持ち出す前に停止理由の内訳で binding かを確かめる。（その163・その166）
- 文献の取得を含む問いは、まず手元の `analysis/*/refs/` を見る。検索エンジンの要約は逐語ではない（要約者の言い換えを逐語と取り違えた失敗が 3 度）。（その134、2026-09-22 の俯瞰）

## 4. 先行研究で占有されていた領域

再提案する前に必ず読む。詳細な一致点・不一致点は `research_loop.md` の「一時停止中の前ゴール」節の「占有されている領域」（タグ側）にある。

- 報告規則を独立した設計対象にする — Peak Identification in Evolutionary Multimodal Optimization（PMC11505590、HVPI と F 値）。GECCO 競技は 2016 年から報告集合の F1 を採点に使う。
- 報告効率の測定 — GECCO 競技の Dynamic F1。
- 持続性による盆地分解・盆地ごとの予算配分 — arXiv 2605.18351（saliency-guided basin-wise budget allocation）。
- 盆地ごとに局所スケールした step-size で再起動 — MSC-CMA-ES（arXiv 2606.15830）。
- 冗長な再起動の回避（tabu / repel）— de Nobel+ 2024（PPSN'24、arXiv 2405.01226、RR-CMA-ES）。系列の最新は ALR-CMA-ES（Swarm Evol. Comput. 2025）。
- 既発見解の近傍への再降下を抑える — RS-CMSA-ES（Ahrari, Deb & Preuss 2017）と MLSL（Rinnooy Kan & Timmer, Math. Prog. 39, 1987）。`Restart-Lander` は MLSL から開始規則 1 行を外したもので、その158 が測った重複は MLSL の "Error 1"。占有は現在形（新 suite の 1 位 TRDE-LR と 2 位 RR-CMA-ES がどちらも持つ。RS-CMSA の著者 Ahrari は新 suite の設計者本人）。
- 多スタートの観測から未発見の個数・停止時刻を推定する — Boender & Rinnooy Kan 1987（Math. Prog. 37）。隣接分野では STADS（arXiv 1803.02130）。
- 盆地サイズの推定を最適化に使う — ABEGA（GECCO 2013）。
- 選抜が広い盆地に偏るという現象 — Information 16(7):583 (2026) のメタ分析。
- 打ち切り閾値をスケールに対して相対に取る — 数値最適化の一般作法（Math. Prog. 57 (1992) ほか）。`hunt_level_tol` の eps 相対化・`basin_reset` の機序はこれ。
- 予算で順位が変わることの指摘と測り方 — moving peak ratio / moving success rate、budget-dependent statistical ranking。
- 多様性対収束のトレードオフ — niching の総説の一般則。MCMC 側に mode coverage の診断（arXiv 2512.17977 ほか）。
- 採点器の ρ（niche radius）依存で峰数を取り違える — PMC11505590、arXiv 2503.18066、IEEE 5586085。
- 目的関数の deflation — Continuation Newton methods with deflation（arXiv 2107.13864 / Numerical Algorithms 2024）。古典側に filled function / tunneling。
- 平滑化・アニーリングで複数モードを同時に探す — Natural Variational Annealing（arXiv 2501.04667、Information and Inference 2026）。
- 無協調の多スタートが niching に勝つという現象 — Lobo & Bazargani（arXiv 1504.06859 が 2015 年初出、EC 誌 30(4) 2022）、Cano+ 2022（Mathematics 10:1494。CEC2013 を使っているとの検索要約は本文未確認）。隣接分野では Den Ottelander+（PPSN 2020、NAS の局所探索ベースライン）。
- 着地点の典型的な間隔に歩幅を合わせて始点を再投入する — basin-hopping（Wales & Doye 1997 以来）。archive から引いて局所に蒔き直すのは MAP-Elites の既定の形。
- 安いスクリーン → 高い精査の 2 相 — successive halving / Hyperband（DEHB、POCA）、two-stage niching、MLSL の global / local phase、Appl. Soft Comput. 2021 の DE ＋ clustering ＋ 2 段局所探索。
- 公表された競技結果が再実装で再現しない — arXiv 2307.07226（生物医学）、ACM TELO の Reproducibility in EC（10.1145/3466624）ほか。
- 次元で協調側と再起動側の首位が入れ替わる — MSC-CMA-ES が単一最適誤差の上で報告（逐語未取得）。
- subset simulation と niching の結婚 — Niching Subset Simulation（Kinnear & DiazDelaO 2025）、arXiv 2604.06417。向きが逆（niching で SuS を直す側）なので直接占有ではない。
- 監査テーマの側 — barrier tree、merge / contour tree、cluster tree 推定、mode connectivity、LON / funnel、Level Set Estimation、Solution Space Engineering。空きと判断したのは成分数を目標にした能動サンプリングなど 4 点だが、総説を読むまで暫定だった。

主張の置き場として残ったのは測定の側だけ: (a) GECCO'2024/'2025 suite と競技の公式 Score の上での 16/16、(b) 報告軸の分解、(c) 合法な報告規則を与えた null が公表最良を上回ること、およびその158 の重複率の測定（引いた 15 本のどれも報告していない）。「多スタートが niching に勝つ」を一般論として書くと Lobo / Cano に潰されるので、論文ではこの区別を明示すること。

新規性の基準（09-08 (1)）:
- 新規性は「組み合わせ」で見る。個々の部品が既存であることは撤退理由にならない。撤退するのは、その組み合わせが先行研究に存在するとき、および概念ではなく具体的な手続きが一致するときだけ。

指標（09-08 (2)、09-11 (1)）:
- 分野で広く使われている指標を使い、自作の指標で判定しない。
