# スライドデザイン まとめノート

出典: `presentation.pdf`（Koya Narumi, Keio University, 情報科学研究補助技法 Summer 2026, Week 3: Slides）
原著: *The Non-Designer's Design Book*

---

## 大前提

- **スライドデザインは自由**：手法は学ぶが、それに縛られる必要はない。
- **品質と時間はトレードオフ**：良い発表には準備時間が必要。どこまで時間を割けるかを考える。
- **発表は研究と同じくらい重要**：誰にも知られない良い研究は意味がない。発表スキルは学外でも一生使える。

---

## Part 1: 基本 — 4つのデザイン原則（守）

> Proximity / Alignment / Repetition / Contrast
> （近接・整列・反復・コントラスト）

### 1. Proximity（近接）
**関連するものは近く、関連しないものは遠くに置く。**

- 視線が彷徨う原因の最大のものは「関連性のなさが空間に反映されていない」こと。
- 適用例:
  - **名刺**：氏名/肩書き/住所/電話番号など、属性ごとにグループ化。
  - **箇条書き**：項目間スペースを項目内行間より大きくする（さもないと項目同士の境界が不明瞭）。
  - **数字（年月日など）**：意味的まとまりごとに間を空ける。
  - **タイトルスライド**：重要な情報を他から離して目立たせる。

### 2. Alignment（整列）
**目に見えない整列線（invisible lines）はできるだけ少なく、はっきりさせる。**

- **「スライド上の全てのオブジェクトは、理由があってその位置に置かれている」状態が理想**。
- 中央揃え（center-aligned text）を安易に使わない:
  - 中央揃えは見えない整列線が左右両方に発生して増える。
  - **基本は左揃え or 右揃え**を選ぶ。
  - ただし、意図して整えた中央揃えはフォーマルで強い印象を与えるので、悪ではない。
- スライド内のオブジェクトが交差する見えない線を作っていないかを常にチェック。

### 3. Repetition（反復）
**繰り返される要素は一貫性を生む。**

- **目次スライドは繰り返し出して良い**：聴衆に「今どこにいるか」を伝える。
- **テンプレートを統一する**：
  - タイトル位置、ページ番号位置、結論位置、引用位置、引用グリッド … を固定。
  - **高さ・位置はピクセル単位で揃える**。微妙なズレは非常に目障り。
- オブジェクトが切り替わるスライドでも、共通部分は1ピクセルも動かさない。

### 4. Contrast（コントラスト）
**意味のあるコントラストは控えめではなく、思いきり強くする。**

- **「大きく変える」か「変えない」か**。中途半端な変化は、意図が伝わらず一貫性も損なう。
- **全てを強調しない**：
  - 「大きいフォントの呪い」に注意（指導教員からよく言われるやつ）。
  - デザイナーは**小さいフォントや余白（white space）も使って**コントラストを作る。
- **新しいトピックに移るときは構造（レイアウト）を変える**ことで切替を明示。

## Part 2: 応用 — 4つのアイデア（破・離）

> Animation / Backgrounds / Eye Motion / Aspect Ratio

### 1. Animation（アニメーション）
**人間はアニメーションを追わずにいられない（カマキリと同じ）。視線誘導に強力。**

- ビデオ発表全体としては実用的でないが、以下の2つは費用対効果が高い:
  - **Translucent transition（半透明トランジション）**：話題の繋がりを示し、聴衆がストーリーを予測しやすくなる。
  - **Opening animation（オープニング動画）**：発表開始30秒で聴衆は興味を失いがち。話す前から内容を伝えられる。

### 2. Backgrounds（背景）
**背景の意味を効果的に使う。**

- **初心者には白背景を推奨**。
- 種類別の長所/短所:
  - **白背景**: 多様な図表が使える、清潔で簡単。
  - **黒背景**: 重厚な雰囲気、ハイコントラスト画像に強い。写真の背景色との相性問題あり。
  - **テクスチャ背景**: ストーリー性は伝えやすい。情報量の多いスライドではノイズになる。
- **意味のない装飾的背景は使わない**。使うなら意味のあるものを選ぶ。
- 意味のある背景は**メッセージスライド**として効果的。

### 3. Eye Motion（視線誘導）
**聴衆の自然な視線の動きを把握する。**

- **「Z字型」が自然な視線の動き**。
- **「コ字型」は避ける**。番号順を辿りづらく不自然。やむを得ない場合はアニメーションで誘導。
- **Proximityも併せて意識**：自然な視線順序と空間的なまとまりは両立させる。
- **Magical Number 7 (or 3)**:
  - 一度にたくさんの項目は読まれない。
  - 多い項目は**小さなバッチにグルーピング**して可読性を上げる。

### 4. Aspect Ratio（アスペクト比）
**好奇心の許す範囲でアスペクト比は自由に選んでよい。**

- **16:9 が第一選択肢**（特に動画を扱うとき）。
- **4:3 もOK**（主に古いプロジェクター向け）。
- **意図的に縦横比を絞る**（例: 2.35:1 シネスコ）:
  - 3文程度の箇条書きはかえって「白すぎる」ことがある。
  - 比を絞ることで聴衆をメッセージに集中させられる。
  - 自己紹介スライドなどで縦長レイアウトも有効。

## Part 3: その他の小ネタ

### 聴衆を小学生だと思う
- 天才教授でさえ、話の **30% しか理解しない**。
- **知っていることを全部話そうとしない**。
- **1スライド1メッセージ**。

### インデントは使わない
- 一見便利だが、見えない整列線が増えてしまう。
- そもそもインデントしなくて済むはず。
- インデントしたくなったら、まず**メッセージの量を減らす**ことを考える。

### Tradeoff: creativity vs workload
- 美しいスライドを作ることが常に正解とは限らない。
- 研究室ミーティングのスライドで時間を浪費しない。
- **そもそもスライドが不要なケースもある**（Google Docs / Notion で済む）。

## 実践チェックリスト

スライドを作るとき or レビューするときに見直す項目:

### Proximity
- [ ] 関連する要素は十分近いか？ 関連しない要素は十分離れているか？
- [ ] 箇条書きの項目間スペースは項目内行間より大きいか？

### Alignment
- [ ] 全てのオブジェクトが意図的に配置されているか？
- [ ] 見えない整列線が増えていないか？（交差していないか）
- [ ] 安易に中央揃えを使っていないか？

### Repetition
- [ ] テンプレート要素（タイトル・ページ番号・引用・余白）は全スライドで一致しているか？
- [ ] スライド間で共通要素がピクセル単位で揃っているか？

### Contrast
- [ ] コントラストは「大きく変える or 変えない」になっているか？
- [ ] 全てを強調していないか？（「大きいフォントの呪い」）
- [ ] 新しいトピックでレイアウトが変わるか？

### Advanced
- [ ] アニメーションは意味のある視線誘導に使われているか？
- [ ] 背景は内容に対して意味があるか？（装飾だけになっていないか）
- [ ] 視線の流れはZ字型に沿っているか？
- [ ] 項目は7個（or 3個）以内にグルーピングされているか？
- [ ] アスペクト比は内容に合っているか？

### Others
- [ ] 1スライド1メッセージになっているか？
- [ ] インデントなしで読めるか？（必要ならメッセージを削れないか）
- [ ] そもそもこのスライドにかける時間は妥当か？

## 一行まとめ

> **「全ての要素は、理由があってその位置・大きさ・色・タイミングで存在する」** — それを Proximity / Alignment / Repetition / Contrast の4原則と、Animation / Backgrounds / Eye Motion / Aspect Ratio の4応用で実現する。
