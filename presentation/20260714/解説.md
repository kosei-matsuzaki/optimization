## p3 — Motivation & goal（動機と目標）

**主張：既存の最適化手法は、それぞれ苦手とする関数の「形」を持っている。**

表は BBOB-24（2次元）ベンチマークでの SR@1e-10（精度 10⁻¹⁰ まで到達できた試行の割合＝成功率）:

| 手法 | 苦手な関数の形 | SR@1e-10 |
|---|---|---|
| CMA-ES · L-SHADE | 多峰性（multimodal, F15–F24） | 32% · 42% |
| PSO · SaVOA | 悪条件（ill-conditioned, F10–F14） | 7% · 18% |
| DE | 曲がった谷・非対称（bent-valley/asymmetric, F06–F09） | 91%（その他はほぼ100%） |

- **多峰性**：山と谷がたくさんあり、局所解に捕まりやすい地形。
- **悪条件（ill-conditioned）**：谷が極端に細長く、方向によって勾配のスケールが桁違いに異なる地形。後述の「条件数（condition number）」が大きい状態。
- 各手法は得意・不得意がはっきり分かれる。

**目標（GOAL）**：ウイルスの「複数経路での拡散」を模すことで、**どんな関数の形に対しても頑健**な単一手法を作る。これが MC-ESO の存在意義。

## p4 — Transmission channels（3つの感染経路）

MC-ESO では各宿主（親個体 `x_p`）が **3つの経路を並行して**子個体を生む。これが手法名の "Multi-Channel"。

1. **Close-contact（接触感染, 青）**：親の近傍に、**集団の散らばりの形に沿った**ガウス分布で子を撒く。局所的な微調整（local Gaussian, C_pop-shaped）。→ 詳細は p15–17。
2. **Droplet（飛沫感染, 赤）**：親から「エリート個体（elite strain, 優秀な解）」へ向かうベクトルを使って子を生む。DE（差分進化）の current-to-best 戦略に相当。優秀な方向へ引っ張る。
3. **Airborne（空気感染, 緑）**：親から遠く離れた広い半径（broadcast radius）にランダムに子を飛ばす。局所解からの脱出（wide random escape）。

3つが同時に走ることで、「近くを丁寧に探る／良い方向へ進む／遠くへ逃げる」を同時に実現する。

## p5 — Population mechanisms（集団を世代間で操る仕組み）

経路が「1個体の子の作り方」なら、こちらは「集団全体を世代をまたいでどう舵取りするか」。3つの機構がある。

1. **Strain coexistence（系統共存, 緑）**：優秀な解（elite）を最大6つまで、**互いに一定距離を保って（kept apart）**同時に維持する。複数の有望領域を並行探索する意図。
2. **Host competition（宿主競合, 橙）**：親（parent）と子（offspring）をまとめて評価し、上位 μ 個だけを次世代に残す **μ+λ 貪欲選択**。改悪した場合は元に戻す（rollback）。
3. **Spillover + drilling（波及＋掘削, 紫）**：停滞した領域（abandoned）を捨て、有望領域へ波及（spillover）してから、その周りで σ（ステップ幅）を縮めて集中的に掘り下げる（tighten σ）。

## p13 — ① Informed restart（情報付きリスタート：実際の挙動）

2次元 BBOB F04 の**実走データ**で、停滞したサブ集団がどう再起動するかを可視化。

## p15 — ② Adaptive anisotropy floor（適応異方性フロア：直感）

接触感染（close-contact）のガウス分布が、**集団の形に合わせて自動で形を変える**様子を、実走データで示す。

- **anisotropy（異方性）= 方向によって広がりが違うこと**。ここでは子を撒くガウス分布の楕円がどれだけ細長いか。
- **左（悪条件の谷 F10）**：集団共分散の固有値比 λmax/λmin ≈ 2×10⁶（極端に細長い）。→ **フロア（下限）を解除**して、楕円を谷に沿って思い切り細長くする（軸比 45:1）。細い谷を滑走するため。
- **右（デコボコ多峰 F15）**：λmax/λmin ≈ 5（あまり細長くない）。→ **フロアを掛けて（clamp）**楕円を丸く保つ（軸比 2:1）。方向を偏らせず慎重に探索するため。

凡例：★ = 親（宿主）、点 = 接触感染で生まれた子、○ = 適応フロア適用後のガウス 2σ 楕円。

要は「谷なら細長く、デコボコなら丸く」を集団の散らばり方から自動判定している。

## p16 — ② Adaptive floor — the math（数式）

接触感染の子を作る流れを、集団の分散共分散行列から順に導く。**太字 = ベクトル/行列、斜体 = スカラー**。

**(1) 子の生成式**
$$\mathbf{x}' = \mathbf{x}_p + \sigma_i\,\mathbf{V}\sqrt{\hat\Lambda}\,\mathbf{z},\quad \mathbf{z}\sim\mathcal{N}(0,\mathbf{I}_d)$$
親 `x_p` に、異方性ガウスノイズを足して子 `x'` を作る。標準正規乱数ベクトル `z`（各成分が独立に平均0・分散1）を、行列 `V√Λ̂` で変形し、スカラー `σ_i` で大きさを掛ける。`V`（向き）・`Λ̂`（各軸の長さ）・`σ_i`（全体スケール）の3つが楕円を決める。

**(2) 集団共分散の固有値分解**
$$\mathbf{C} = \mathrm{Cov}(\mathbf{x}_1,\dots,\mathbf{x}_n) = \mathbf{V}\Lambda\mathbf{V}^\top$$
いま生きている個体たちの**分散共分散行列 C**（集団が空間にどう散らばっているか）を**固有値分解**する。C は対称半正定値なので、直交行列 `V`（列が固有ベクトル＝散らばりの主軸方向）と対角行列 `Λ=diag(λ)`（固有値＝各主軸方向の分散＝広がりの2乗）に分解できる。これは主成分分析（PCA）と同じ操作で、`V` が「楕円の向き（回転）」、`λ` が「各軸方向の広がり」を与える。谷が斜めに走っていれば、集団も谷に沿って散らばるので `V` の第1主軸が谷の向きになる。

**(3) 細長さの測定と指数移動平均（EMA）**
$$r = \lambda_{\max}/\lambda_{\min},\quad \rho \leftarrow (1-\beta)\rho + \beta\log_{10}r$$
`r` = 最大固有値 ÷ 最小固有値 = **条件数**（楕円が最長軸と最短軸でどれだけ引き伸ばされているか）。ただし瞬間値の `log₁₀ r` をそのまま使わず、**指数移動平均（EMA, exponential moving average）**で平滑化した `ρ` を使う。
- EMA は「新しい値を重み `β`、これまでの累積を重み `1−β` で混ぜる」更新則（ここで `β=0.1`）。過去の値が指数関数的に減衰しながら効くので、直近を重視しつつ履歴も残す。
- 目的は**一時的なスパイクを無視すること**。ある世代でたまたま集団が細長くなっても、それが持続しない限り `ρ` は大きく動かない。「持続的な細長さ」だけに反応させる。
- log を取るのは、条件数が 10³〜10⁶ と桁で変動するため。桁（オーダー）の空間で平均・補間する方が素直。

**(4) 細長さ ρ からフロア φ を決める（clip と幾何補間）**
$$t = \mathrm{clip}\!\left(\frac{\rho-\log r_{lo}}{\log r_{hi}-\log r_{lo}},\,0,\,1\right),\quad \varphi = \varphi_{hi}\,(\varphi_{lo}/\varphi_{hi})^t$$
- 前半：`ρ` を 0〜1 の割合 `t` に正規化する。`log r_lo = log₁₀(1e3) = 3`、`log r_hi = log₁₀(3e4) ≈ 4.48` を下端・上端として、「`ρ` がこの区間のどこにいるか」を線形に測る。`clip(…,0,1)` は区間外を端に丸める（`ρ<3` なら 0、`ρ>4.48` なら 1）。→ `t` は「細長さの進み具合メーター」。
- 後半：`t` を使ってフロア `φ` を `φ_hi=1e-2` と `φ_lo=1e-3` の間で**幾何補間（＝指数を線形補間）**する。`φ = 1e-2 · (0.1)^t` なので、`t=0 → 1e-2`（デコボコ：フロアきつく、楕円を潰させない）、`t=1 → 1e-3`（悪条件：フロア緩く、細長い楕円を許す）。
- なぜ普通の線形補間（`φ = 1e-2 + t(1e-3−1e-2)`）にしないか：1e-2 と 1e-3 は1桁違うので、線形だと `t=0.5` で φ≈5.5e-3 と 1e-2 側に張り付き、変化が後半に偏る。指数で結べば `φ = 10^{−2−t}` となり、`t` が 0.1 増えるごとに常に同じ倍率（≈0.79倍）で縮む、均等な補間になる。

**(5) フロアの適用（正規化 → 持ち上げ → 再正規化）**
$$\tilde\lambda_i = \lambda_i/\bar\lambda,\quad \hat\lambda_i = \max(\tilde\lambda_i,\varphi),\quad \hat\Lambda = \mathrm{diag}(\hat\lambda)/\overline{\hat\lambda}$$
- まず固有値を平均で割り、**平均が1になるよう正規化**（`λ̃`）。
- `φ` より小さい軸を `φ` まで**持ち上げる**（`max`）。＝薄すぎる方向に最低限の厚みを与える。
- 持ち上げで総量が増えるので、**もう一度平均1に再正規化**（`Λ̂`）。
- 正味の効果：**全体の大きさ（ステップ量）は変えず、楕円の細長さにだけ上限を掛ける**。

**(6) 宿主ごとの全体スケール σ_i**
$$\sigma_i = \sigma\cdot\rho_{\min}^{\,q(0.7+0.3a)}$$
楕円の「向き」と「形」を (2)–(5) で決めた後、**大きさ**は個体ごとに調整する。`q` = 解の質（quality, 0–1、良いほど大）、`a` = 齢（age, 0–1、古いほど大）、`ρ_min=0.05`。**質が高く古い宿主ほど σ_i を縮めて周囲を丁寧に掘る（活用/exploit）**、質が低い宿主は σ を大きく保って**広く探る（探索/explore）**。指数部で質と齢を掛けているので、両方が高いと最も強く収縮する。

## p17 — ② Adaptive floor — result（結果）

フロアなしでも SR は既に約90%あり、**フロアの効果は「1e-10 手前で稀に停滞する種を潰すこと」**にある。2つの悪条件楕円関数で収束曲線を比較。

- 各行：2次元マップ／3次元地形／1e-10 への収束曲線。
- 灰 = フロアなし（abl1）、赤 = 適応フロア（abl2）。縦軸 `best f − f*`（最適値との差）を対数で、横軸が評価回数。
- **F02-EllipsoidalSep（seed 500）**・**F10-EllipsoidalRot（seed 300）**とも、フロアなしは 10⁻⁵ 付近で停滞して 1e-10 目標に届かない（×印）。適応フロアは 1000 評価程度で 10⁻¹¹ まで一直線に収束。

つまり平均性能ではなく、**「ごく稀に起きる収束の取りこぼし」を確実に潰す**のがこの機構の価値。p11 の +3.1pt（1e-10）がこれに対応。

## p18 — ③ Per-landscape channel router（地形別チャネルルーター）

**地形の種類を共分散のシグナルから判定し、空気感染（airborne）の予算を最適な1経路へ振り向ける。**

左：判定ロジック（covariance signals → one route）。
- **cond > 3**（条件数が大）→ **DROPLET**（悪条件の谷。飛沫で優秀方向へ引く）。
- **algA & mgap high**（分離可能性の指標が高い）→ **CLOSE**（分離可能。接触感染で軸ごとに詰める）。
- **それ以外** → **KEEP-AIR**（多峰。base のまま空気感染を保つ）。

`cond`（条件数）・`algA`・`mgap` はいずれも**目的関数値に依存しない、共分散から計算できる量**（f-independent signals）。関数の正解を知らなくても地形タイプを推定できる点が肝。

右の要点:
- **What changed**：run を共分散シグナルで分類し、空気予算を1経路へルーティング。
- **Why it works**：最適な空気予算の振り先は地形の形で違う／一律の再配分は必ず悪化した（uniform reallocation always regressed）／ルーティングされない run は base とビット単位で同一（挙動を壊さない安全設計）。
- **Result**：F04/F11/F12/F13/F14/F16 で広く改善（Broad +5）、全体 +0.8pt。

---

## p19 — ④ Route-gated best2（経路限定の2次差分）

**飛沫（droplet）経路にのみ、2本目の差分ベクトルを足す。**

左：飛沫の差分構造。
- **single（base）**：`x_p + F(x_strain − x_p)` — 親からエリート系統への1本の差分（DE の基本形）。
- **route-gated**：`… + F(x_c − x_d)` — さらに**2本目の差分**（ランダムな2個体 `x_c, x_d` の差）を追加。
- 2次差分 = ドナーの多様性 → 間違った谷からの脱出。飛沫経路のみ・経路外はビット単位で同一。

右の要点:
- **What changed**：飛沫経路のみ 2本目の差分ベクトルを追加。4つ目のチャネルは作らない（No 4th channel）。
- **Why it works**：1本の差分だと間違った谷で停滞する／2本目でドナーの多様性が増え脱出できる／既存スロットを差し替える（in-place swap）ので、無駄スロットによる乱数列のズレ（dead-slot RNG shift）を避けられる。
- **Result**：F13 SharpRidge 55 → 100（+45）、F14 DiffPowers 75 → 100（+25, Wilcoxon large）、全体 +2.1pt。

「4つ目の経路を新設せず、既存の飛沫経路の中身を差し替える」設計思想（新チャネル追加は他 run の乱数列をずらして壊すため避ける）。

---

## p20 — Process data moved too（過程データも改善：谷を約2倍速で収束）

成功率だけでなく**成功までの評価回数（evals-to-success, 少ないほど速い）**も改善した。悪条件の谷で比較（灰 = 5/18 base、赤 = MC-ESO）。

- F11 Discus：1207 → 559（**2.2×**）
- F12 Bent Cigar：1192 → 569（**2.1×**）
- F13 Sharp Ridge：1273 → 631（**2.0×**）

右の3点:
- **Overall speed-up**：BBOB-24 平均で 950 → 790 評価（−17%）。
- **Same SR, half the evals**：F11/F12/F13 は同じ 100% 到達を約半分の評価で達成。
- **Median hits machine zero**：F13/F14 は best2 適用後、中央値の best-f が 0.0（機械精度のゼロ）に到達。

「同じ成功率をより速く」＝実用上の効率も上がったことを示す。

## p21 — 章4 扉：Multimodality

第4章は「もう一方の軸＝多峰性（多解探索）」の部分的な進捗と、残る課題。

---

## p22 — Multimodality — the facade, quantified（見かけ倒しを定量化）

**SR は 100% に飽和しているのに、実は大域最適解のほとんどを見つけられていない。**

- **PR@1e-4（peak ratio）= K 個ある大域最適解のうち、精度 1e-4 で見つけられた割合**。SR は「1つでも見つけたか」だが、PR は「いくつ見つけたか」を測る多解性の指標。

| 関数（最適解数 K） | K | PR@1e-4 | SR@1e-10 | restart-CMA |
|---|---|---|---|---|
| C01 Himmelblau | 4 | 0.28 | 100% | BIPOP 0.78 |
| C02 Six-hump | 2 | 0.60 | 100% | — |
| C03 Shubert | 18 | 0.06 | 100% | BIPOP 0.11 |

SR@1e-10 は全て 100%（1解は深く到達）だが、PR は Himmelblau で 0.28、Shubert では 0.06 しかない＝**4解中1解、18解中1解しか捕まえていない**。

**系統共存は不活性だった（Strain coexistence was inert）**：35関数中30関数で、実際に生きているエリート数（live n_elite）≈ 1。つまり p5 で設計した「複数系統の並行維持」は事実上 no-op（何もしていない）だった。→ これが**逐次 niching（sequential niching）**を導入する動機になった。

---

## p23 — Sequential niching（逐次 niching：解を増やしつつ SR は不変）

**niching = 見つけた最適解の周囲を「占有済み」として、次の探索を別の解へ誘導する多解探索の手法。**「逐次」は、並行ではなく1つずつ順番に掘り出す方式。

- **左（Peak ratio @ 1e-4, 上昇）**：5/18 base → +niching → MC-ESO の推移。
  - C02 Six-hump（K=2）：0.60 → **100%**
  - C01 Himmelblau（K=4）：0.28 → **53%**
  - C03 Shubert（K=18）：0.06 → **17%**
- **右（SR @ 1e-10, 不変）**：3関数とも全区間で **100% に固定**。

下部注記：**2レジーム設計** — ある谷を掘り切るまでは base と完全に同一に動き、掘り切った後に**リスタートを反発させて次の最適解へ向かわせる**。この設計により、多解性能を上げながら **SR@1e-10 を1ミリも下げない**（プロジェクトの絶対ルール）を守れる。

---

## p24 — Multimodality — still only partial（まだ部分的）

正直な限界の明示。

- **Full multi-solution not reached**：MMO success @1e-4（全解を捕まえる基準）は Himmelblau/Shubert で依然 0%。すべての最適解は捕まえきれていない。
- **The dilemma（ジレンマ）**：複数の谷を**並行して**深く掘ると SR@1e-10 が崩れる。深精度（1解を深く） vs 全解カバー（多くの解を）の本質的トレードオフ。
- **Deliberate scope（意図した範囲設定）**：今回は性能軸を優先し、多峰性は「SR を損なわない範囲」でのみ進めた。

下部：Shubert の PR@1e-4 は 0.06 → 0.17 と**3倍**に。実質的な前進はあるが、絶対水準はまだ低い、と率直に評価。

## p26 — Summary（まとめ）

- **Idea（着想）**：一律のチャネル混合 → **地形に応じたルーティング**（目的関数値に依存しないシグナルで判定）。
- **Mechanism（機構）**：情報付きリスタート + 適応フロア + ルーター + 経路限定 best2（+ niching）。
- **Result（結果）**：SR@1e-10 が 86.9 → **92.9%**（BBOB-24, +6.0pt, 全10手法中トップ）／谷は約2倍速で収束／多解性能↑・SR は維持。

4つの改良を「何を・なぜ・数値で」の順で積み上げてきた本報告の総括。

## p27 — Remaining work & next steps（残課題と次の一手）

- **Multimodality**：SR@1e-10 を犠牲にせず、全解カバー（MMO）を達成すること。p24 のジレンマを解く必要がある。
- **Stuck-run escape**：停滞 run からの脱出。4つ目の「媒介（migratory）チャネル」は**却下**した — 救出された run と元々壊れている run を区別できなかったため。新しい機構が必要。
- **Higher dimensions**：dim3・CEC2022 dim10 の hold-out には汎化を確認済み。dim ≥ 20 と実問題は今後の課題（宿題①）。

## 全体を貫くテーマ

1. **診断駆動（diagnosis-driven）**：まず何が弱点かを定量診断（p3, p6, p22）してから改良を設計する。
2. **地形認識（landscape-aware）**：目的関数値に依存しない共分散シグナルで地形タイプを推定し、それに応じて挙動を切り替える（p15–18）。
3. **SR@1e-10 の死守**：どの改良も深精度成功率を下げない。多解探索ですら SR を守れる2レジーム設計にする（p8, p23）。
4. **既存を壊さない設計**：ルーティングされない run・経路外はビット単位で base と同一に保ち、新チャネル追加による乱数列のズレを避ける（p18, p19）。
